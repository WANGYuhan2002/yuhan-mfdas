## 一、目录角色

本目录存放来自 NOA（雅典国家天文台）的已审核地震目录，以及 DAS 光缆通道-地理坐标映射文件。是整个 MF 流程的**最上游输入**，数据由 NOA 官方网站手动下载（文件头标注 `GEIN NOA Reviewed Event Bulletin`，人工审核公报）。

本目录**无脚本**，被以下 release 内的脚本消费：

| 消费者 | 使用文件 | 用途 |
|--------|----------|------|
| `Run_0/.../1_SNR_Mag_control_find_NOAeq_SatisfyStalta_OverlapUseTime.py` | `100km_distance/IMS_...319.txt` | 模板筛选：提取 FSK 到时，筛选满足 SNR/震级条件的 NOA 事件作为模板候选 |
| `Run_0/.../3_Similarity_control_delete_similar_eqs.py` | `100km_distance/IMS_...319.txt` | 模板相似度控制：同样读取 100km IMS |
| `Run_4/.../2b_Est_Mag_with_GR_law_check.py` | `200km_distance/IMS_...263.txt` | 震级赋值：时间+空间双重匹配将 MF 检测事件与 NOA 事件对应，赋 NOA 官方震级（ML） |
| `Run_6/.../1_label_STALTA_with_template_plus_NOAeq.py` | `200km_distance/IMS_...263.txt` | STA/LTA 目录增强：时间匹配标注 NOA 震级与位置 |
| `Run_6/.../2_label_NOA_with_template_and_detectByMForNot.py` | `200km_distance/IMS_...263.txt` | NOA 目录标注：空间+时间双重标注 MF 检测情况 |
| `Run_6/.../4_plot_detection_power_mag_dist_map.py` | `200km_distance/IMS_...263.txt` | 提取台站代码列表，用于地图标注台站位置 |
| `Run_6/.../4_plot_detection_power_mag_dist_map_CHANGE_LAYOUT.py` | `200km_distance/IMS_...263.txt` | 同上（横版布局） |

**100km IMS** 被 Run_0（模板筛选阶段）消费；**200km IMS** 被 Run_4（震级赋值阶段）与 Run_6（对比分析阶段）消费。`EPI_*.txt` 与 `kefa_chan_map.csv` 不属于本 release 主流程（见下）。

## 二、100km_distance vs 200km_distance

两个子目录格式相同，区别在于地震事件的震中距范围（以 DAS 光缆/研究区为中心）：

| 参数 | 100km_distance | 200km_distance |
|------|----------------|----------------|
| IMS 文件 | `IMS_20240425_20240623_319.txt` | `IMS_20240425_20240623_263.txt` |
| EPI 文件 | `EPI_20240425_20240623_823.txt` | `EPI_20240425_20240623_856.txt` |
| 实际事件数 | 728 个 | 2083 个 |
| 震级范围（ML） | 0.1–4.1 | 0.1–4.3 |
| 纬度范围 | 37.48°N–39.23°N | 36.72°N–40.19°N |
| 经度范围 | 19.73°E–21.69°E | 19.08°E–22.87°E |
| 主要消费者 | Run_0（模板筛选） | Run_4 / Run_6（震级赋值与对比） |

时间范围相同：2024-04-25 至 2024-06-23（约 59 天）。

**用途差异**：
- 100km 版本用于 Run_0 模板筛选，DAS 光缆附近范围内的事件质量较可靠，适合筛选高质量模板。
- 200km 版本用于震级回归与 NOA 对比，需要更大范围确保 FSK 台站有足够记录次数（200km IMS 中 FSK 记录 904 个事件，100km 版本为 653 个）。

## 三、IMS 格式 vs EPI 格式

同一批地震事件以两种格式提供：

| 格式 | IMS（完整台站震相公报） | EPI（震中参数简表） |
|------|------------------------|---------------------|
| 格式标准 | IMS1.0:LONG 国际标准 | NOA 简表 |
| 内容 | 完整记录：事件定位参数 + 每个台站的 P/S 到时 + 振幅 | 仅事件摘要（时间、位置、震级、统计量） |
| 距离单位 | 度（文件内注明 "All distances are expressed in degrees"） | 千米（km） |
| 结构 | 多行 per 事件，以 `\n\nSTOP\n\n` 分隔 | 单行 per 事件，空格分隔 |
| 主流程使用 | **是**（Run_0/4/6 均读取 IMS） | **否**（EPI 不被本 release 任何脚本读取） |

**IMS 是主流程输入**，EPI 仅作归档/快速浏览用途。

## 四、IMS 文件格式说明

**命名规律**：`IMS_<起始日期>_<截止日期>_<ID>.txt`（末尾数字为 NOA 系统内部编号，不等于事件数）。

**每个事件块结构**（以 `\n\nSTOP\n\n` 分隔）：

```
DATA_TYPE BULLETIN IMS1.0:LONG
GEIN NOA Reviewed Event Bulletin
EVENT <event_id> <地名描述>
   Date       Time       Err   RMS  Latitude Longitude  ... Depth  Ndef Nsta ...
<事件摘要行>

Magnitude  Err Nsta Author ...
<震级行>

Sta     Dist  EvAz Phase        Time       TRes  ...  Amp  Magnitude  ArrID
<台站到时行1>
<台站到时行2>
...
```

**事件摘要行关键列**：

| 列 | 含义 | 单位 |
|----|------|------|
| Date / Time | 发震时刻（UTC） | YYYY/MM/DD HH:MM:SS.S |
| Latitude / Longitude | 震源位置 | 度 |
| Depth | 震源深度 | km |
| Ndef / Nsta | 定位震相数 / 台站数 | 个 |
| mdist / Mdist | 最近/最远台站距离（**注意：单位为度，非 km**） | 度 |

**台站到时行关键列**：

| 列 | 含义 | 单位 |
|----|------|------|
| Sta | 台站代码（如 FSK、AMPL、PDO 等） | — |
| Dist | 震中距 | 度 |
| EvAz | 方位角 | 度 |
| Phase | 震相类型（P_1、S_2 等） | — |
| Time | 台站观测到时（当日 UTC） | HH:MM:SS.SS |
| Amp | 振幅（ML 振幅） | µm |
| Magnitude | 该台站贡献的 ML 值 | 无量纲 |

**FSK 台站提取**：所有主流程脚本均通过 `functions/extract_station_info.extract_station_info(file_path, 'FSK')` 专门提取 **FSK 台站**（Fiskardo 台，Kefalonia 岛）的到时记录。返回字段：`EQ_time, EQ_latitude, EQ_longitude, EQ_depth, EQ_magnitude, STA_name, STA_distance(度), STA_azimuth, STA_phase, STA_arrival_time`。

## 五、EPI 文件格式说明

**命名规律**：`EPI_<起始日期>_<截止日期>_<ID>.txt`。

**格式**：固定宽度空格分隔文本表格，第一行为列标题，后续每行一个事件。

| 列名 | 含义 | 单位 |
|------|------|------|
| Date / Time | 发震时刻（UTC） | YYYY/MM/DD HH:MM:SS.S |
| Latitude / Longitude | 震源位置 | 度 |
| Depth | 震源深度 | km |
| Magnitude | 地方震级 ML | 无量纲 |
| Ndef / Nsta | 定位震相数 / 台站数 | 个 |
| RMS | 走时残差均方根 | 秒 |
| Gap | 方位角空隙 | 度 |
| mdist / Mdist | 最近/最远台站距离 | km（EPI 格式距离单位为 km，与 IMS 不同） |
| Namp | 用于震级计算的振幅读数数量 | 个 |

**EPI 不被本 release 任何流程脚本读取**，仅作归档保留。

## 六、kefa_chan_map.csv（DAS 通道地理坐标映射）

**格式**：CSV，1705 个通道记录（含 16 个占位零行）。

| 列名 | 含义 | 单位/说明 |
|------|------|-----------|
| Latitude | 通道光缆位置纬度 | 度，约 38.42°N–38.46°N |
| Longitude | 通道光缆位置经度 | 度，约 20.56°E–20.64°E |
| Elevation | 海拔高度（地下负值） | 米，约 -163.7 m 至 +158.3 m |
| Name | 通道名称（格式 `D<整数>`，如 D135, D13922） | DAS 通道序号 |

负海拔通道表示光缆沿海底延伸的部分。

**本 release 主流程（Run_0 至 Run_6）不读取此文件**。该文件供论文图制作（光缆走向绘图）使用，属附属地理元数据，随附保留。
