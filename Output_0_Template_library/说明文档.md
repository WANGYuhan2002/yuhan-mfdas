## 二、本文件夹角色

本文件夹是整个 matched filter 流程的**模板库最终落地处**，是全下游唯一的模板来源。

- **上游**：`Run_0_preparing_templates_from_catalog/` 完成候选事件筛选（SNR/震级控制→互相关→去重），产出 `dup_temp_df.csv`。在此基础上，作者对候选列表进行人工精选，形成 `Template_library.csv` 基础版（含 `infile_name / plot_name / plot_order / t_P_sec / t_S_sec` 等人工标注列）。
- **本文件夹做的事**：对已定稿的 5 个模板进行复核（重算互相关、重切 npy、补 SNR/能量字段），不重跑 Run_0 的筛选/去重流程。脚本 1→2→3 是「复核/再产出/补字段」的定稿闭环。
- **下游**：`Template_library.csv` 与 `Template_npy_files/*.npy` 是 Run_1 及之后全部步骤的唯一模板输入，必须完整保留。

## 四、脚本逐个说明

### 脚本 1：`1_check_again_Comp_corr_between_events_v6.py`

- **作用**：对最终定稿的 5 个模板重新计算两两叠加归一化互相关矩阵与时移矩阵。是 Run_0 脚本 2（`2_Comp_corr_between_events_v6.py`）的复核版，算法相同，输入改为定稿模板表。
- **与 Run_0 脚本 2 的差异**：输入从「候选集 `matched_df.csv`」改为「`Template_library.csv` 的 `t_start` 列」；时间窗 `t_left/t_right/t_pad` 由 10/20/10 s 改为 5/50/20 s；输出目录改到 `Check_again_corr_map_waterfall/`；矩阵图每格额外标注数值。
- **输入**：
  - `Template_library.csv`（取 `t_start` 列作为事件起始时刻）。
  - 连续 DAS 数据。
  - 参数：`fs=80`、`freq_band=[8,20]`、`t_left=5s`、`t_right=50s`、`t_pad=20s`、通道 8.3–14 km、`n_workers=20`。
- **输出**（写入 `Check_again_corr_map_waterfall/`）：
  - `correlation_matrix.npy`（`(5,5) float32`，两两归一化互相关，对角=1）
  - `offset_matrix.npy`（`(5,5) int32`，最佳对齐样本时移；÷80=秒）
  - `config.json`、`correlation_matrix_abs.png`、`offset_matrix.png`、`offset_matrix_abs.png`。
- **核心逻辑**：模板波形读入共享内存 → 预计算滑动标准差 → `ProcessPoolExecutor` 并行 FFT 互相关（`signal.fftconvolve`）、按通道归一化求和、取绝对值最大 → 保存矩阵与图。
- **依赖 functions**：`readers`（Read_DAS_data, write_pkl, load_pkl）、`plot`、`load_das_h5_PE2024`、`stalta`、`cluster`（read_DAS_span 等）。

### 脚本 2：`2_check_again_map_Produce_templates_from_EQs.py`

- **作用**：从定稿模板表按时间窗切取每个模板的**原始未滤波 DAS 波形**，存为 `Template_npy_files/*.npy`，同时出单模板瀑布图与总览图。是 Run_0 脚本 4 的复核/再产出版（`save_as_temp_or_not=1`，真正产出 npy）。
- **与 Run_0 脚本 4 的差异**：输入改读 `Template_library.csv`（而非 `dup_temp_df.csv + corr_matrix`）；`freq_band=[8,20]`（Run_0 为 [5,20]）；`das_dist_start=8.3e3`（Run_0 为 8e3）；npy 文件名用 `infile_name` 字段；`save_as_temp_or_not=1`（实际产出 npy）。
- **输入**：
  - `Template_library.csv`（取 `t_start, t_end, t_P_sec, t_S_sec, infile_name, plot_name, plot_order, EQ_*, STA_*` 等列）。
  - `Check_again_corr_map_waterfall/correlation_matrix.npy`（脚本 1 产物，用于总览图）。
  - 连续 DAS 数据。
- **输出**：
  - `Template_npy_files/{infile_name}.npy` ——**本文件夹最核心产物**，每个模板的原始未滤波波形（`(time, 936通道) float64`）。
  - `Check_again_corr_map_waterfall/{infile_name}_ML{mag}_dist{d}.png`（单模板瀑布图）。
  - `Check_again_corr_map_waterfall/ALL_templates_waterfall_map.png`（5 模板总览图）。
  - `Check_again_corr_map_waterfall/config.json`。
- **核心逻辑**：逐行读模板时间窗 → 读原始数据（`load_das_h5_PE2024.load_das_custom`）→ 存 npy（不滤波、不裁通道）→ 滤波/裁通道仅用于出图 → 拼总览图（GridSpec，按 `plot_order` 排序）。
- **依赖 functions**：`plot`、`das_mffi_io`、`load_das_h5_PE2024`、`pydas_readers`、`compute_correlation.preprocess`。出图需 geopandas/cartopy/contextily/adjustText。

### 脚本 3：`3_add_SNR_and_Energy_peakAmp_for_Template_library.py`

- **作用**：给 `Template_library.csv` 追加 5 个字段并覆盖写回，产出最终 27 列定稿表。Run_0 中无对应脚本，本文件夹独有。
- **输入**：
  - `Template_library.csv`（读取，取时间/到时/infile_name 列）。
  - `Template_npy_files/{infile_name}.npy`（脚本 2 产出，经 `Read_template` 裁通道+滤波后计算 self-CC）。
  - 连续 DAS 数据（算 P/S/噪声窗 RMS）。
  - 关键参数：`SNR_win_P=[0.2,1.5]`、`SNR_win_S=[0.2,2.0]`、`SNR_win_prepad=[30,2]`（P/S 窗、噪声前导窗，单位秒）。
- **输出**：**覆盖写** `Template_library.csv`，新增列：
  - `SNR_S, SNR_P`：S/P 窗信噪比（信号 RMS/噪声 RMS）。
  - `self_CC`：模板自相关能量 `mean(sum(temp*temp, axis=0))`。
  - `amp_max_mean`：S 窗各通道峰值绝对值的均值。
  - `amp_log_mean`：其 log10 均值（供振幅→震级标定）。
- **核心逻辑**：由 `t_P_sec/t_S_sec + t_start` 定位 P/S 到时 → 取 S/P/噪声窗二维 RMS → 算 SNR → 算 self-CC 与峰值振幅 → 写回 CSV（`index=False`）。
- **依赖 functions**：`readers`（Read_DAS_data, Read_template）、`compute_correlation.preprocess`、`load_das_h5_PE2024`。
- **重要提示**：这是**唯一会覆盖写 `Template_library.csv`** 的脚本，必须在脚本 2 产出 npy 后运行。

### 脚本 4：`4_check_again_map_and_template_waterfall_plot_for_paper.py`（出图，可忽略）

- **作用**：论文出图专用，重画「5 模板瀑布+相关矩阵+地图」高品质大图，样式高度参数化（字体/配色/子图编号 a)~g)）。不产出任何 npy 数据。
- **输入**：`Template_library.csv`（含脚本 3 的 SNR 列）、`Check_again_corr_map_waterfall/correlation_matrix.npy`、连续 DAS 数据。
- **输出**：`Check_again_corr_map_waterfall_for_paper/ALL_templates_waterfall_map.png` + `config.json`。
- **依赖 functions**：`plot.Ticks_xaxis_minute_or_second`、`load_das_h5_PE2024`、`compute_correlation.preprocess`。
  - **注意**：脚本把外部出图仓库 `GRL_DAS_MF_plots/functions/`（不在本 release 内）以后备路径 `external/GRL_DAS_MF_plots/functions/` 加到 `sys.path` 末尾；这三个函数在本包 `functions/` 中也有，实际先从 `functions/` 导入（见第一节的说明）。

## 五、脚本执行顺序与数据流

```text
（前置：Run_0_preparing_templates_from_catalog 全流程 + 作者人工精选）
            │
            ▼
   Template_library.csv  ← 人工定稿基础版（22 列，含 infile_name/plot_name/t_P_sec/t_S_sec 等）
            │
            ▼
[脚本 1] 1_check_again_Comp_corr_between_events_v6
            │  → Check_again_corr_map_waterfall/correlation_matrix.npy (5×5)
            │  → Check_again_corr_map_waterfall/offset_matrix.npy (5×5)
            ▼
[脚本 2] 2_check_again_map_Produce_templates_from_EQs
            │  读 correlation_matrix.npy（脚本 1）
            │  → Template_npy_files/*.npy  【核心数据产物】
            │  → Check_again_corr_map_waterfall/*.png（单模板/总览图）
            ▼
[脚本 3] 3_add_SNR_and_Energy_peakAmp_for_Template_library
            │  读 Template_npy_files/*.npy（脚本 2）
            │  → Template_library.csv（覆盖写，追加 SNR_S/SNR_P/self_CC/amp_max_mean/amp_log_mean → 27 列）
            ▼
[脚本 4] 4_..._for_paper（可选，依赖外部仓库）
            │  读 Template_library.csv（27 列）+ correlation_matrix.npy
            │  → Check_again_corr_map_waterfall_for_paper/ALL_templates_waterfall_map.png

            Template_library.csv（27 列）+ Template_npy_files/*.npy
            │
            ▼
   Run_1 ~ 全部下游步骤（唯一模板来源）
```

**依赖要点**：脚本 2 依赖脚本 1（要 correlation_matrix.npy）；脚本 3 依赖脚本 2（要 npy 算 self-CC）；脚本 4 依赖脚本 1（矩阵）+ 脚本 3（SNR 列）。下游 Run_1 起步只需脚本 2 的 npy + 脚本 3 完善后的 csv。

## 六、核心数据文件说明

### `Template_library.csv`（最终定稿表，下游全靠它）

当前为 **5 行 × 27 列**（5 个最终模板），由脚本 3 覆盖写得到 27 列版。

| 字段组 | 列名 | 说明 |
| --- | --- | --- |
| STA/LTA 触发 | `peak_time, peak_amp, peak_score, max_amp_mean` | DAS 触发时刻与指标；`peak_amp ≈ SNR²` |
| NOA 匹配 | `match_or_not, time_diff_sec` | 与 NOA 目录匹配标志及时间差 |
| 台站/DAS | `STA_arrival_time, STA_distance, STA_azimuth` | 到时、距离（单位**度**，×111→km）、方位角 |
| NOA 震源 | `EQ_time, EQ_latitude, EQ_longitude, EQ_depth, EQ_magnitude` | 发震时刻、经纬度、深度(km)、本地震级 ML |
| 聚类 | `cluster` | DBSCAN 聚类标签（-1=孤立） |
| 模板时窗 | `t_start, t_end` | 模板切片时间窗（UTC 字符串） |
| 人工标注 | `t_P_sec, t_S_sec` | 相对 `t_start` 的 P/S 到时（秒） |
| 文件名/出图 | `infile_name, plot_name, plot_order` | npy 文件名（不含 .npy）；短标注名 Temp_K1~I2；画图排序 0–4 |
| 脚本 3 追加 | `SNR_S, SNR_P, self_CC, amp_max_mean, amp_log_mean` | S/P 信噪比、模板自相关能量、S 窗峰值振幅均值及其 log10 |

当前 5 个模板：ML 2.4/2.5/4.1/3.1/3.0，距 DAS 约 0.12–0.33 度（约 13–37 km）。

### `Template_npy_files/*.npy`（模板波形，脚本 2 产出，全下游消费）

| 文件 | shape (time, chan) | dtype |
| --- | --- | --- |
| `template_0423_80Hz.npy` | (641, 936) | float64 |
| `template_0425_80Hz.npy` | (881, 936) | float64 |
| `template_10_80Hz.npy` | (1121, 936) | float64 |
| `template_20_80Hz.npy` | (721, 936) | float64 |
| `template_8_80Hz.npy` | (961, 936) | float64 |

内容：**原始未滤波** strain-rate 波形；时间长度 = `(t_end - t_start) × 80`；936 通道为全 DAS 通道数。下游消费方式：`functions/readers.py::Read_template` 加载后裁到 8.3–14 km（第 508:857 通道，共 349 通道），再 8–20 Hz 带通滤波。文件名与 `Template_library.csv` 的 `infile_name` 一一对应。

**重要**：`Template_library.csv` 与 `Template_npy_files/*.npy` 是全下游唯一模板来源，务必完整保留。

### 模板间矩阵（脚本 1 产出）

- `Check_again_corr_map_waterfall/correlation_matrix.npy`：`(5,5) float32`，模板两两归一化叠加互相关，对角=1，非对角约 ±0.02~0.04（模板间几乎不相关，去重成功的佐证）。被脚本 2、4 读入画图。
- `Check_again_corr_map_waterfall/offset_matrix.npy`：`(5,5) int32`，最佳对齐时移（采样点；÷80=秒）。

### 留存参考文件（本文件夹脚本均不读写，仅记录）

- `matched_df_with_clusters.csv`：Run_0 去重步骤的全候选+聚类标签表（64 行×17 列），快照留存。
- `dup_temp_df_SNR30.csv`（12 行）/ `dup_temp_df_SNR40.csv`（10 行）：Run_0 在 SNR30/SNR40 两档阈值下的去重结果，本文件夹脚本读取代码已注释，纯留底参考。
- `Template_library_K16_I13_F14.csv`（13 模板，24 列）/ `Template_library_M2.csv`（5 模板，22 列）：早期/候选版模板表，与定稿 `Template_library.csv` 不一致（模板数量/命名/震级不同），下游不读它们，仅作历史记录。

## 七、check_again 脚本与 Run_0 的关系

| 本文件夹脚本 | Run_0 对应脚本 | 关系 |
| --- | --- | --- |
| `1_check_again_Comp_corr_between_events_v6` | `Run_0/2_Comp_corr_between_events_v6` | 算法相同，输入改为定稿表（5个模板），时间窗参数略有调整（5/50/20s vs 10/20/10s） |

核心区别：Run_0 的脚本面向「从候选集自动筛选/去重」，本文件夹的脚本面向「对已人工定稿的 5 个模板进行复核/再产出/补字段」，两套脚本**不可互换**。
