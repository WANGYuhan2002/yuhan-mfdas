# Output_1_SCCs_and_MAD 说明文档

> **GitHub 版说明：** 下文描述的本目录数据文件不在本仓库里，在 Zenodo 存档 [10.5281/zenodo.20715241](https://doi.org/10.5281/zenodo.20715241)（`matched_filter_release.zip` → `yuhan_dasmf_v1.0/Output_1_SCCs_and_MAD/`）。文中说数据「随 release 附带 / 已在 release 中」，都指该存档。要运行读取这些文件的脚本，请把它们拷回相同的相对路径。

## 本 release 内容分类

本文件夹是 matched_filter 流程的**第 1 阶段数据产物**，以数据为主，含一个出图辅助脚本。

**数据**（由 `Run_1_compute_SCCs_and_MAD/` 的主线脚本产生，被下游 Run_2/Run_3 消费）：

- `SCCs_h5/<模板>/CCs_stack_*.h5`：叠加互相关时间序列，核心中间数据。
- `MAD_arrays/.../MAD_Average_dict.pkl`：整段平均 MAD，Run_2 触发阈值的基准。
- `MAD_arrays/.../*.pkl`（其余 5 个）：逐时窗统计量，诊断/出图用。

**出图脚本（可忽略）**：

- `MAD_arrays/999_plot_MADarr_with_meteo_and_stalta.py`：把 MAD 时序与气象数据叠加出图，属分析辅助，非检测主流程。**依赖气象模块** `IN_noise_meteo/load_kefa_meteo.py`（外部 check_minmag 工程的模块，已拷入本包，按包内相对路径导入）及其读取的两个 ERA5 CSV（在 Zenodo 存档里；GitHub 版 `IN_noise_meteo/` 只有模块，CSV 见配套仓库 `WANGYuhan2002/yuhan_das_spectra` 的 `meteo/` 及 Zenodo `check_minmag_pkg/meteo/`）。

## 一、文件夹在整体流程中的位置

本文件夹保存两类产物：叠加互相关时序（SCCs）与 MAD 阈值基准。

**上游（产生本文件夹数据的脚本）**：

- `Run_1_compute_SCCs_and_MAD/1_Compute_SCCs_10min_h5_Parallel_io_once.py` → 产出 `SCCs_h5/`。
- `Run_1_compute_SCCs_and_MAD/2_MAD_of_SCCs_calculation_Parallel.py` → 读 `SCCs_h5/`，产出 `MAD_arrays/`。

Run_1 主线脚本的输入来源：

- 模板 npy：`{PROJECT_ROOT}/Output_0_Template_library/Template_npy_files/`（Run_0 产生）。
- 连续 DAS：80 Hz 归档 `DATA_DEC_80Hz_16m_SORTED/`，默认位置 `IN_DAS_data/continuous_scan_1h/`（外部数据）。

**下游（消费本文件夹数据的步骤）**：

- `SCCs_h5/` → **Run_2**（触发）、**Run_3**（峰值振幅），均经 `functions/readers.py:Read_CCs_stack_h5` 读取。
- `MAD_arrays/.../12:00:00/MAD_Average_dict.pkl` → **Run_2** 触发脚本，用作各模板平均 MAD（阈值 = MAD × level）。

整体流程：`Run_0（模板库）→ Run_1（本文件夹数据的产生者）→ 【Output_1：本文件夹】→ Run_2（触发）→ Run_3（峰值振幅）→ 后续分析`。

## 二、脚本说明

### `MAD_arrays/999_plot_MADarr_with_meteo_and_stalta.py`

**作用**：把逐小时 MAD 时序、模板匹配检测数直方图、气象数据（有效波高 SWH + 风速）叠加画汇总图，用于比较「SCC 噪声水平 / 检测率」与「海浪/风」的相关性。属出图辅助，不产生中间数据，不在检测主流程关键路径上。

**输入**：

- `MAD_arrays/20240424_102000_to_20240622_171000/1:00:00/MAD_array_dict.pkl`（由 Run_1 产生）。
- `{PROJECT_ROOT}/Output_0_Template_library/Template_library.csv`（模板显示名与排序）。
- 气象模块 `load_kefa_meteo`（外部 check_minmag 工程的模块，原在其 `check_minmag_validity/Run_4_amp_spec/wind_speed/`；现拷在本包 `IN_noise_meteo/`）。
- 关键参数（`Config` 类硬编码）：`t_start=2024-04-24 10:20`、`t_end=2024-06-22 17:10`、`time_delta_minutes=60`。

**输出**：`MAD_arrays/20240424_102000_to_20240622_171000/1:00:00/Summary_Plot_MAD_Meteo_MF_Combined_v2.png`（同目录下已有的 `Summary_Plot_*` 旧图为历史产物）。

**注意**：依赖 `IN_noise_meteo/` 下的气象数据（在 Zenodo 存档或配套仓库 `WANGYuhan2002/yuhan_das_spectra` 的 `meteo/` 中）与下游分类结果（`Output_4`），只能在完整流程跑完并放入所需数据后运行。

## 三、数据格式说明

### 3.1 `SCCs_h5/` — 叠加互相关时序

**目录结构**：

```
SCCs_h5/
  config.json                    ← 运行参数记录
  template_0423_80Hz/
    CCs_stack_template_0423_80Hz_UTC_YYYYMMDD_HHMMSS.ffffff.h5
    ...（每10分钟一个文件）
  template_0425_80Hz/  ...
  template_10_80Hz/    ...
  template_8_80Hz/     ...
  template_20_80Hz/    ...
```

5 个模板子目录，**本 release 每个模板附带 2024-04-25 当天的样本数据（144 个文件，对应一天 144 个 10 分钟窗口）**，作为示例子集。全量数据覆盖 2024-04-24 10:20 至 2024-06-22 17:10（每模板约 8537 个文件），可由 `Run_1_compute_SCCs_and_MAD/1_Compute_SCCs_10min_h5_Parallel_io_once.py` 在连续 DAS 归档（`IN_DAS_data/continuous_scan_1h/`）可用时重新计算。

**文件命名**：`CCs_stack_<模板名>_UTC_<YYYYMMDD>_<HHMMSS.ffffff>.h5`，文件名时间为该 10 分钟窗口的 UTC 起点。

**文件内容**（h5py，含两个一维 dataset，无 attrs）：

| dataset | shape | dtype | 含义 |
| --- | --- | --- | --- |
| `CCs_s` | `(48001,)` | float64 | 叠加互相关时序：该 10 分钟窗内所有 DAS 通道归一化互相关沿通道轴取均值。`48001 = 10 min × 60 s × 80 Hz + 1`，量级约 ±0.01。 |
| `RAWCCs_s` | `(48001,)` | float64 | 原始（未归一化）互相关的通道均值，量级极小（约 1e-5 量级），供后续估算相对振幅用。 |

**采样率**：80 Hz（与 DAS 去采样率一致）。

**读写接口**：`functions/readers.py:write_h5`（写）、`Read_CCs_stack_h5`（读，按 `t_start~t_end` 自动定位并跨文件拼接连续 `CCs_s`/`RAWCCs_s`）。

**`SCCs_h5/config.json`**（记录产生本文件夹数据时的运行参数）：

```json
{
  "fs": 80,
  "freq_band": [8, 20],
  "das_dist_start": 8300.0,
  "das_dist_end": 14000.0,
  "dx": 16.335...,
  "Temp_name_list": ["template_0423_80Hz", "template_0425_80Hz",
                     "template_10_80Hz", "template_8_80Hz", "template_20_80Hz"]
}
```

### 3.2 `MAD_arrays/` — MAD 阈值基准

**目录结构**：

```
MAD_arrays/
  999_plot_MADarr_with_meteo_and_stalta.py    ← 出图脚本
  20240424_102000_to_20240622_171000/          ← 时间段（t_start_to_t_end）
    1:00:00/    ← 统计时窗 = 60 分钟（主用）
    12:00:00/   ← 统计时窗 = 720 分钟（探索/对比用）
```

时间段目录名 = `{t_start:%Y%m%d_%H%M%S}_to_{t_end:%Y%m%d_%H%M%S}`；时窗子目录名 = `str(timedelta(minutes=nt_delta))`（60 min → `"1:00:00"`，720 min → `"12:00:00"`）。

**每个时窗子目录下的 pkl 文件**（均为标准 pickle dict，key = `'t_array'` + 5 个模板名）：

| 文件 | 各模板值 shape（1h 窗） | 含义 |
|---|---|---|
| `MAD_array_dict.pkl` | `(1423,)` | 逐时窗 MAD = nanmedian(\|x − nanmedian(x)\|)，触发阈值的核心基准。 |
| `Median_array_dict.pkl` | `(1423,)` | 逐时窗 SCC 中位数。 |
| `MEAN_array_dict.pkl` | `(1423,)` | 逐时窗 SCC 均值。 |
| `MEANAbsDev_array_dict.pkl` | `(1423,)` | 逐时窗 nanmean(\|x − nanmean(x)\|)，平均绝对偏差。 |
| `PeakCCs_array_dict.pkl` | `(1423,)` | 逐时窗 SCC 绝对值峰值 nanmax(\|CCs_s\|)。 |
| `MAD_Average_dict.pkl` | 每模板 `(1,)`，`t_array` 为首尾两点 | 整段观测期各模板的平均 MAD。**Run_2 触发读取 `12:00:00/MAD_Average_dict.pkl`，以此计算触发阈值（阈值 = 平均 MAD × level）。** |

`t_array`：时窗边界的 datetime 数组，1h 窗时 shape `(1424,)`（边界数 = 段数 + 1）。

**配套出图**（由 Run_1 步骤 2 直接产生）：`SCCs_MAD_array_AllTemp.png`、`SCCs_Statistics_array_AllTemp_inOne.png`。`Summary_Plot_*` 系列由本文件夹 `999` 脚本产生（见第二章）。

**产生者**：`Run_1_compute_SCCs_and_MAD/2_MAD_of_SCCs_calculation_Parallel.py`。

**主要消费者**：`MAD_Average_dict.pkl` → Run_2 触发脚本；`MAD_array_dict.pkl` → `999` 出图脚本。
