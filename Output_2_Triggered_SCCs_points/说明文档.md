## 一、文件夹概述与在整体流程中的位置

**作用：** 保存触发点（trigger points）。即对每个模板在 SCCs 时间序列上，`|SCCs|` 超过 `MAD × Threshold_level` 阈值的候选检测点，聚类取局部极大后记录，附带 CC 值、原始互相关、宽度、边界时刻及 SCCs 上的 STA/LTA 峰值（`max_stalta`），供下游去重、分类与排假阳性使用。

**在整体流程中的位置：**

```
Output_1_SCCs_and_MAD/SCCs_h5/       (上游：连续 SCCs，10 分钟一个 h5)
Output_1_SCCs_and_MAD/MAD_arrays/    (上游：每模板 MAD 阈值基准)
            │
            ▼
   Run_2_trigger_SCCs_kurtosis/
   1_Trigger_SCCs_eachTemp_byMADandLevel_constThres_Parallel.py
            │
            ▼
 ===> 本文件夹 Output_2_Triggered_SCCs_points/level_XX/template_*/CCs_trig_*.pkl <===
            │
            ├──► Run_3_record_peakAmp/     (在触发时刻记录 DAS 峰值振幅)
            ├──► Run_4_assign_overlaps_with_kurtosis/  (去重叠、分类、估震级；强依赖 max_stalta)
            └──► Run_5_fk_exclude_false_positive/      (f-k 分析排假阳性)
```

## 二、目录结构与命名规律

```
Output_2_Triggered_SCCs_points/
├── level_15/   level_20/   level_25/   level_30/   level_35/   level_40/   level_50/
│   ├── config.json                         ← 该 level 运行时的参数副本（由 Run_2 写出）
│   ├── template_0423_80Hz/
│   ├── template_0425_80Hz/
│   ├── template_10_80Hz/
│   ├── template_20_80Hz/
│   └── template_8_80Hz/
│       └── CCs_trig_<template>_UTC_<YYYYMMDD>_<HHMMSS.ffffff>.pkl
```

- **`level_XX`**：`XX = Threshold_level`，即触发阈值的 MAD 倍数。触发判据为 `|SCCs(t)| > MAD_template × Threshold_level`（见 `functions/trigger.py::Trigger_with_MADarray`）。现存 `level_15/20/25/30/35/40/50` 共 7 档，为参数扫描结果；level 越大越严格，触发数单调减少。
- **`template_*_80Hz`**：5 个模板子目录，对应 5 个模板（`template_0423/0425/10/20/8`，采样率 80 Hz）。
- **文件名 `CCs_trig_<template>_UTC_<时间>.pkl`**：`<时间>` 为该 10 分钟切片的起点 UTC（格式 `YYYYMMDD_HHMMSS.ffffff`）。文件覆盖 `[t_start, t_start+10min)`；**只有切片内有触发点时才写出 pkl**（空切片不落盘）。
- **时间范围：** `2024-04-24 10:20:00 → 2024-06-22 17:10:00`（约 59 天）。
- **规模：** 全文件夹共约 55,379 个 pkl，约 223 MB。

## 三、每个 pkl 的内部结构

`pkl` 是一个 `dict`，含 10 个键，所有数组长度相同（= 该 10 分钟切片内的触发点个数 N）：

| 字段 | 类型/形状 | 含义与单位 |
| --- | --- | --- |
| `t_trig` | ndarray[datetime], (N,) | 触发点时刻（该聚类内 `\|SCCs\|` 最大处，UTC） |
| `CCs_s_trig` | ndarray[float64], (N,) | 触发点处 SCCs 值（带符号，约 [-1,1]） |
| `RAWCCs_s_trig` | ndarray[float64], (N,) | 触发点处原始互相关值（未归一化；下游用于震级估计） |
| `width_trig` | ndarray[timedelta], (N,) | 触发聚类的时间宽度（`t_right - t_left`） |
| `t_left` | ndarray[datetime], (N,) | 触发聚类左边界时刻（首个超阈样本） |
| `t_right` | ndarray[datetime], (N,) | 触发聚类右边界时刻（末个超阈样本） |
| `SCCs_of_MAD` | ndarray[float64], (N,) | `CCs_s_trig / MAD_template`，绝对值 ≥ `Threshold_level` 才被触发 |
| `max_RAWCCs` | list[float], (N,) | `[t_left, t_right]` 窗内 `\|RAWCCs\|` 最大值（带符号）；空窗 NaN |
| `t_arg_max` | list[datetime], (N,) | `max_RAWCCs` 对应时刻 |
| `max_stalta` | list[float], (N,) | 触发点附近 `search_win=[0.6,0.2]s` 窗内 SCCs 的 STA/LTA（未归一）最大值；下游 Run_4 用此字段做假阳性过滤；空窗 NaN |

`max_stalta` 是 kurtosis 版核心附加字段。下游 `functions/readers.py::Read_CCs_trig_pkl` 强依赖此键，Run_4 与 Run_5 均须此字段存在。

## 四、config.json（每个 level 子目录各一份）

由 Run_2 主线脚本在运行时写出，记录产生该 level 数据时的完整参数：

| 字段 | 含义 |
| --- | --- |
| `Threshold_level` | 该 level 的 MAD 倍数阈值（15/20/.../50，与目录名一致） |
| `Minimal_event_interval` | 同一聚类内事件最小间隔（秒） |
| `IN_CCs_stack_dir` | 输入 SCCs 来源目录 |
| `MAD_Avg_path` | 输入 MAD 基准路径 |
| `OUTPUT_dir` | 输出目录（即本文件夹对应 level 子目录） |
| `fs` | 采样率 80 Hz |
| `Temp_name_list` | 参与触发的 5 个模板 |
| `sta_len / lta_len` | SCCs 上算 STA/LTA 的短/长窗（秒），0.5 / 1.5 |
| `search_win` | 触发点左右搜 STA/LTA 峰值的窗口（秒），[0.6, 0.2] |

## 五、下游消费方式

`functions/readers.py::Read_CCs_trig_pkl(IN_CCs_trig_dir, Template, t_start, t_end)` 会：
1. glob 该 `template_*` 目录下所有 `*.pkl`；
2. 从文件名解析 10 分钟切片起点，按时间窗筛文件；
3. 拼接全部字段（含 `max_stalta`）后按 `t_trig` 裁剪返回。

下游各步通过 `Threshold_level` 参数选择消费哪一套 level 目录的触发结果：

- **Run_3**：在触发时刻记录 DAS 峰值振幅。
- **Run_4**：去重叠、分类、估震级；`max_stalta > 阈值` 用于过滤假阳性。
- **Run_5**：f-k 分析排假阳性，也读 `max_stalta`。
