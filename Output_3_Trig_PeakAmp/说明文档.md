> **GitHub 版说明：** 下文描述的本目录数据文件不在本仓库里，在 Zenodo 存档 [10.5281/zenodo.20715241](https://doi.org/10.5281/zenodo.20715241)（`matched_filter_release.zip` → `yuhan_dasmf_v1.0/Output_3_Trig_PeakAmp/`）。文中说数据「随 release 附带 / 已在 release 中」，都指该存档。要运行读取这些文件的脚本，请把它们拷回相同的相对路径。

## 本 release 脚本分类

本文件夹无脚本。数据由 **Run_3（主线）** 产生，供下游震级估计脚本消费。

---

## 一、文件夹概述与在整体数据流中的位置

**作用**：存放 Run_3 对每个触发事件提取的 DAS 峰值振幅数据。每个 level 子目录下：逐事件的 349 维振幅数组（per-event pkl）与全事件的标量振幅汇总表（`Trig_MAX_amp_df.csv`）。

```
Output_1_SCCs_and_MAD (MAD)
Output_0_Template_library (模板库 csv)
Output_2_Triggered_SCCs_points (触发点 pkl)
        │
        ▼  Run_3_record_peakAmp/1_Record_Amp_Parallel.py
        │     读触发点 → 回 DAS 数据取峰值振幅
        ▼
【本文件夹】Output_3_Trig_PeakAmp
        │     · level_{N}/{Template}/amp_max_at_Rt_trig_*.pkl（逐事件 349 维振幅）
        │     · level_{N}/Trig_MAX_amp_df.csv（每事件峰值振幅汇总，下游消费）
        ▼  震级估计脚本 2b_Est_Mag_with_GR_law_check.py
              读 Trig_MAX_amp_df.csv，取 amp_log_mean/amp_max_mean 列
              → 准震级 → G-R 律 / b 值
```

**上游**：Output_2 触发点 + Output_0 模板库 + Output_1 MAD + DAS 原始连续数据（80 Hz 归档 `DATA_DEC_80Hz_16m_SORTED/`，脚本从包内默认位置 `IN_DAS_data/continuous_scan_1h/` 读取）。

**下游**：震级估计脚本（位于本 release 的下游 Run 文件夹），只读 `Trig_MAX_amp_df.csv`，不直接读 per-event pkl。

`level_<N>`：触发阈值倍数子目录，与上游 `Output_2_Triggered_SCCs_points/` 的 level 子目录一一对应（15/20/25/30/35/40/50）。level 越高触发越少，事件数单调下降（例如 level_15 约 43k 行，level_50 约 6k 行）。

## 三、数据文件说明

### 1. `level_{N}/Trig_MAX_amp_df.csv`（下游消费文件）

- **格式**：制表符分隔，16 列：`CCs_s_trig, RAWCCs_s_trig, t_trig, width_trig, t_left, t_right, max_RAWCCs, t_arg_max, max_stalta, Rt_trig, Rt_left, Rt_right, CCs_s_trig_ofMAD, Template, amp_max_mean, amp_log_mean`。一行 = 一个触发事件。
- **关键列**：
  - `amp_max_mean`：`mean(amp_max)`，各通道峰值振幅的算术平均。
  - `amp_log_mean`：`mean(log10(abs(amp_max)+1e-12))`，对数平均，**下游震级估计脚本用作准震级（Quasi_Mag）**。
- **下游用法**：`2b_Est_Mag_with_GR_law_check.py` 按 `['Rt_trig', 'Template']` merge，取 `amp_log_mean`/`amp_max_mean` 列合并到分类事件表，令 `Quasi_Mag = amp_log_mean`，再与 NOA 目录震级做线性回归得 `Real_Mag`，并据此画 G-R 律、估 b 值与完备震级 M_c。

### 2. `level_{N}/{Template}/amp_max_at_Rt_trig_<Rt_trig>.pkl`（逐事件振幅，备查）

- **命名**：`<Rt_trig>` 为去除模板 S 波偏移后的真实事件触发时刻（精确到秒，`%Y-%m-%d %H:%M:%S`）。
- **格式**：Python dict，含以下核心键：

  | 键 | 类型 | 含义 |
  |----|------|------|
  | `Rt_trig` / `Rt_left` / `Rt_right` | Timestamp | 事件真实时刻及触发窗左右端 |
  | `t_trig` / `t_left` / `t_right` | Timestamp | CC 上触发位置及实际取数据时窗 |
  | `Template` | str | 触发模板名，如 `template_0423_80Hz` |
  | `CCs_s_trig_ofMAD` | float | SCC / MAD（检测强度） |
  | `amp_max` | ndarray float64, shape=(349,) | 各 DAS 通道峰值振幅（349 通道，8300–14000m 段，单位 DAS 应变率量级） |
  | `t_max` | DatetimeIndex, len=349 | 各通道峰值出现时刻 |
  | `amp_max_mean` | float | `mean(amp_max)` |
  | `amp_log_mean` | float | `mean(log10(abs(amp_max)+1e-12))`，准震级 |

- **由谁产生**：Run_3。**被谁消费**：下游无脚本直接读取此 per-event pkl，属于保留逐通道明细的备查数据，下游估震级只用 CSV 中的标量列。

### 3. `level_{N}/Trig_MAX_amp_df_checkpoint.pkl`

Run_3 断点续传缓存，内容与 `Trig_MAX_amp_df.csv` 基本一致，下游不消费。

### 4. `level_{N}/config.json`

Run_3 运行参数与全部输入/输出路径的落盘记录（`Threshold_level`、`fs`、`freq_band`、`das_dist_start/end`、`dx`、`Temp_name_list`、`Search_win_*`、`num_cpus`、各路径等），是「该 level 数据由何参数产生」的权威证据。
