## 一、文件夹概述与在整体流程中的位置

本文件夹是 **Run_4（带峰度判据的去重叠分类）流程的最终结果文件夹**，承载整个 matched-filter 流程的**最终地震目录**及其震级/b值/滑移/地震矩等下游产物与论文图件。

**上游输入（由 Run_4 脚本读取）：**

- `Output_0_Template_library/Template_library.csv`：模板库元数据（含 `self_CC`、`amp_max_mean`、`amp_log_mean`、`t_P_sec`、`t_S_sec`、`plot_name`、`plot_order` 等）。
- `Output_1_SCCs_and_MAD/SCCs_h5/`：连续叠加互相关 SCCs（h5）。
- `Output_1_SCCs_and_MAD/MAD_arrays/.../12:00:00/MAD_Average_dict.pkl`：各模板平均 MAD 值（阈值归一化基准）。

- `Output_3_Trig_PeakAmp/level_20/Trig_MAX_amp_df.csv`：触发时刻的 DAS 峰值振幅（`amp_max_mean`、`amp_log_mean`），供 2b 估震级用。
- `IN_NOA_cata/200km_distance/IMS_20240425_20240623_263.txt`：NOA/IMS 真实地震目录（台 FSK），用于把准震级标定到真实 ML。
- 噪声趋势文件（仅 5_ 系列出图用）：包内 `IN_noise_meteo/noise_trends_f8-20Hz_p5.h5`（外部 check_minmag 工程 `check_minmag_validity/Run_4_amp_spec_final/...` 的产物；在 Zenodo 存档里，GitHub 版不含，同名成品见配套仓库 `WANGYuhan2002/yuhan_das_spectra` 的 `products/` 及 Zenodo `check_minmag_pkg/products/`）。
- STA/LTA 对照目录（仅 3a 出图用）：包内 `IN_STALTA_cata/sta_lta_catalog.csv`（外部 STA/LTA 工程 `stalta_clustering/Output_1_STALTA_catalog_v1/.../sta_lta_catalog.csv` 的副本；在 Zenodo 存档里，GitHub 版不含）。

**下游去往：**

- `Run_6_get_and_compare_STALTAinMF_NOAinTemp_MF/`：读取本文件夹的 `Events_classified_Real_Mag.csv`，把 MF 目录与 STA/LTA、NOA 目录三者对比，评估检测能力（最终主线下游）。

**核心产物**：`level_20/MagRegression/Events_classified_Real_Mag.csv` 是带震级的**最终地震目录**，是本 release 对外发布的核心数据。

## 二、各子目录/产物由 Run_4 哪个脚本产生

产生脚本均位于 `Run_4_assign_overlaps_with_kurtosis/`。以「本文件夹中的产物 ← 脚本」组织。

### 2.1 `level_20/Events_classified_AllTemp.csv` 与 `Events_classified_AllTemp_addRAWCCs.csv` 与 `level_20/config.json`

**← `2a_Classification_byCCs_with_kurtosis.py`（主线核心脚本）**

- **作用一句话**：把 5 个模板的所有触发点收集到一起，按 `max_stalta>10` 过滤假触发、按 2.5s 时间窗做多模板去重叠（同一真实地震的重复触发），用 |CCs/MAD| 最大者代表该事件，输出全量分类表。
- **输入**：
  - 模板库 `Output_0_Template_library/Template_library.csv`（5 个模板，按 `plot_order` 排序）；
  - 触发点目录 `Output_2_Triggered_SCCs_points/level_20/`（含 `max_RAWCCs/t_arg_max/max_stalta`）；
  - MAD 平均字典 `Output_1_SCCs_and_MAD/MAD_arrays/.../MAD_Average_dict.pkl`。
  - 关键参数：`Threshold_level=20`、`IN_one_event_interval=2.5s`、`max_stalta_threshold=10`、时间窗 `2024-04-24 10:20:00 ~ 2024-06-22 17:10:00`、`fs=80`、`freq_band=[8,20]`。
- **输出**：
  - `level_20/config.json`（本脚本全部参数/路径的权威记录）；
  - `level_20/Events_classified_AllTemp.csv`；
  - `level_20/Events_classified_AllTemp_addRAWCCs.csv`（**与前者内容字节级相同**，见备注）。
- **核心处理逻辑**：
  1. `Read_Collapse_group_df`：逐模板读触发 pkl → DataFrame，计算 `Rt_trig/Rt_left/Rt_right`（用模板 S_offset 还原真实发震时刻）、`CCs_s_trig_ofMAD = CCs_s_trig / MAD`、`Template` 列，按 `Rt_trig` 排序。
  2. 用 `max_stalta>10` 掩码删除低质量触发。
  3. `Collapse_with_MAX_CCs(..., 2.5)`：按 `Rt_trig` 相邻间隔 >2.5s 划分新组（`is_new_group`/`group`），每组内 `|CCs_s_trig_ofMAD|` 最大行标 `Belong_or_not=1`。
  4. 写出两份 csv。
- **备注**：脚本中 `max_RAWCCs` 由上游 Output_2 已记录好（「处理办法 2」），从 SCCs h5 重算的「处理办法 1」已注释掉。因此 `Events_classified_AllTemp_addRAWCCs.csv` 实际与 `Events_classified_AllTemp.csv` 字节级相同（`_addRAWCCs` 为历史命名遗留，并未额外加列）。
- **实测**：共 17,326 条检测（其中 17,325 条在截至 2024-06-22 16:15 的分析时窗内；跨模板合并重叠检测后为 17,263 条，即 `Belong_or_not==1`）；各模板触发行数：`0423`(12469)、`0425`(2436)、`10`(1958)、`20`(242)、`8`(221)。

### 2.2 `level_20/MagRegression/` 全部内容

**← `2b_Est_Mag_with_GR_law_check.py`（主线核心脚本，紧接 2a 运行）**

- **作用一句话**：给最终事件估算震级——先用 max_RAWCCs 经 self_CC/峰值振幅标定得到「准震级 Quasi_Mag」，再用与 NOA/IMS 真实震级的线性回归把准震级标定到「真实震级 Real_Mag」，并出 G-R 律检查图。
- **输入**：
  - `level_20/Events_classified_AllTemp_addRAWCCs.csv`（主输入）；
  - `Output_3_Trig_PeakAmp/level_20/Trig_MAX_amp_df.csv`（按 `['Rt_trig','Template']` 左连接拿到 `amp_log_mean`、`amp_max_mean`）；
  - 模板库（用 `self_CC`、`amp_max_mean` 算标定因子 `fac_CC2amp`）；
  - NOA/IMS 目录（台 FSK，经 `extract_station_info` 解析）。
  - 关键参数：`method='max_RAWCCs'`、匹配时差 `t_ERR=5s`、回归经纬度搜索 ±0.05°、每模板需 ≥3 个匹配才做标定。
- **输出（均写入 `level_20/MagRegression/`）**：
  - `Events_classified_Real_Mag.csv`：**最终带震级地震目录**（在最终事件表上追加 `amp_log_mean/amp_max_mean/Quasi_Mag_Amp/fac_CC2amp/Quasi_Mag/Real_Mag`）。
  - `Events_with_NOA_Mag/<Template>_Events_with_NOA_Mag.csv`：每模板一份，MF 事件与 NOA/IMS 真实事件按时差 <5s 配对拼接，用于标定回归。
  - `Events_with_NOA_Mag/Quasi_Mag_to_NOA_Mag.png`：各模板 Quasi→Real 线性拟合图。
  - `GR_law_check/Real_Mag_GR_law.png`、`GR_law_check/Quasi_Mag_GR_law.png`：连续累计 G-R 律 + b值/a值拟合。
  - `max_RAWCCs_vs_peakAmp/max_RAWCCs_vs_peakAmp.png`：Quasi_Mag vs Quasi_Mag_Amp 一致性散点。
- **核心处理逻辑**：
  1. 合并 `Trig_MAX_amp_df` 拿振幅，按时间窗裁剪。
  2. `Quasi_Mag_Amp = amp_log_mean`；逐模板 `fac_CC2amp = amp_max_mean/self_CC`，`Quasi_Mag = log10(|max_RAWCCs × fac_CC2amp|)`。
  3. `_find_Template_EQs_in_IMS`：在 NOA/IMS 中按模板震中 ±0.05°、时差 <5s 找匹配事件，拼接 NOA Mag 列。
  4. 若某模板匹配 ≥3 个 → 最小二乘拟合得 `slope/intercept`，`Real_Mag = Quasi_Mag×slope + intercept`；不足则该模板 Real_Mag 留空。
  5. `from_catalog_to_GR_law` 出 Real/Quasi 两套 G-R 律。
- **实测各模板 NOA 匹配事件数**：`template_0423`=195、`template_10`=121、`template_0425`=38、`template_8`=32、`template_20`=4（`template_20` 仅 4 个，标定可信度低）。

## 四、数据与中间数据说明（最重要）

本章详列本文件夹保存的数据文件的逐列字段。所有 csv 均为 **Tab 分隔**，时间列格式 `YYYY-MM-DD HH:MM:SS.ffffff`。

### 4.1 `level_20/Events_classified_AllTemp.csv`（= `..._addRAWCCs.csv`）

- **产生**：`2a_Classification_byCCs_with_kurtosis.py`；**消费**：`2b`（主输入）、`3a`。
- 实测共 17,326 条检测（其中 17,325 条在截至 2024-06-22 16:15 的分析时窗内；跨模板合并重叠检测后为 17,263 条，即 `Belong_or_not==1`）。

| 列名 | 含义 / 单位 |
| --- | --- |
| `CCs_s_trig` | 触发点处的叠加互相关系数 SCC（已归一化，约 ±0.1 量级），带符号 |
| `RAWCCs_s_trig` | 触发点处的未归一化叠加互相关（量级 ~1e-13，幅度正比于真实振幅） |
| `t_trig` | 触发时刻（模板时间系，未去模板内 P/S 时差） |
| `width_trig` | 触发段宽度（timedelta，秒级） |
| `t_left` / `t_right` | 触发段左/右边界（模板时间系） |
| `max_RAWCCs` | 触发段内 \|RAWCCs\| 最大值（量级 ~1e-13）；估震级核心量 |
| `t_arg_max` | `max_RAWCCs` 出现时刻 |
| `max_stalta` | 触发段对应的 STA/LTA 峰值（>10 才保留）；kurtosis 质量判据 |
| `Rt_trig` | **真实发震时刻**（= t_trig 去掉模板 S_offset，对齐到真实地震） |
| `Rt_left` / `Rt_right` | 真实时间系下的左/右边界 |
| `CCs_s_trig_ofMAD` | `CCs_s_trig / 该模板平均MAD`（即"超过多少倍 MAD"，触发阈值=20） |
| `Template` | 模板 `infile_name`（5 个之一：`template_0423_80Hz` 等） |
| `Belong_or_not` | 去重叠后标志：1=该组代表事件（最终目录采用），0=被并入同组的重复触发 |
| `is_new_group` | 是否为新事件组的起点（True/False） |
| `group` | 事件组编号（同一真实地震的多次触发共享一个 group） |

### 4.2 `level_20/MagRegression/Events_classified_Real_Mag.csv` ★最终地震目录

- **产生**：`2b_Est_Mag_with_GR_law_check.py`；**消费**：`2b_999`、`3b`、`5_*`、下游 Run_6。
- 实测共 17,326 条检测（其中 17,325 条在截至 2024-06-22 16:15 的分析时窗内；跨模板合并重叠检测后为 17,263 条，即 `Belong_or_not==1`）。列 = 4.1 全部列 **+ 以下 6 列**：

| 列名 | 含义 / 单位 |
| --- | --- |
| `amp_log_mean` | 该触发的 DAS 峰值振幅「先取 log10 后跨通道平均」（log10 应变率，约 -8 量级）；来自 Output_3 |
| `amp_max_mean` | 该触发的 DAS 峰值振幅「先跨通道平均后取最大」（线性，~1e-9 应变率）；来自 Output_3 |
| `Quasi_Mag_Amp` | = `amp_log_mean`，即直接用 DAS 峰值振幅对数得到的准震级 |
| `fac_CC2amp` | 该模板 CC→振幅缩放因子 = `amp_max_mean / self_CC`（每模板一常数），把未归一化 CC 折算到峰值应变率量纲 |
| `Quasi_Mag` | 准震级 = `log10(\|max_RAWCCs × fac_CC2amp\|)`（无量纲对数振幅，~ -9 量级）；G-R 律 b 值在此尺度等价 |
| `Real_Mag` | **真实局部震级 ML** = `Quasi_Mag×slope + intercept`（按各模板对 NOA/IMS 线性标定）；模板匹配事件不足 3 个时留空 |

- **去向说明**：`Real_Mag` 是最终对外震级；`Quasi_Mag` 用于 G-R 律内部检查；滑移/地震矩由 `Real_Mag` 经 Brune 公式在 5_ 出图脚本内即时计算，**不落盘到 csv**。

## 五、核心含义备注

- `max_stalta`：触发时刻邻域内 STA/LTA 特征函数（`sl_unnorm`）的峰值，在 Run_2_kurtosis 阶段算好存入触发 pkl；代码与图中作为「Kurtosis」质量判据，越大越像真震，阈值 10 用于筛假触发。
- `fac_CC2amp = amp_max_mean / self_CC`：把未归一化的模板互相关振幅折算到峰值应变率量纲的标定因子，每模板一常数。
- `Quasi_Mag`（基于 max_RAWCCs）与 `Quasi_Mag_Amp`（基于 amp_log_mean）是两种准震级估计路径；`Real_Mag` 是对 `Quasi_Mag` 做 NOA 线性标定后的最终结果。
- 滑移/地震矩仅在 5_ 出图脚本内即时计算，不落盘到 csv：`Slip = (σ^(2/3)/μ)×571.73×10^(0.5×Mw)`（Brune，σ=1MPa，μ=30GPa），滑移方向由 `CCs_s_trig` 正负赋予；`Moment = 10^(1.5×(Mw+6.03))` N·m。
- b 值参数在 3b 与 `5_` 系列之间有意不同：3b 用 `minimum_events=80/step=0.2h/mc=minmag`，`5_` 系列用 `minimum_events=100/step=2h/mc=maxc`，出图用途不同，非互相替代关系。
