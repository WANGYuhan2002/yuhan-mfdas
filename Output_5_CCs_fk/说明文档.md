# Output_5_CCs_fk 说明文档

> **GitHub 版说明：** 下文描述的本目录数据和图件不在本仓库里，在 Zenodo 存档 [10.5281/zenodo.20715241](https://doi.org/10.5281/zenodo.20715241)（`matched_filter_release.zip` → `yuhan_dasmf_v1.0/Output_5_CCs_fk/`）。文中说数据「随 release 附带 / 已在 release 中」，都指该存档。要运行读取这些文件的脚本，请把它们拷回相同的相对路径。

> 本文件夹是 `Run_5_fk_exclude_false_positive/` 的输出目录，存放针对模板匹配触发点所做的「假阳性诊断」可视化结果，全部为 PNG 图和 config.json，**不含任何数组/目录类中间数据，没有下游脚本消费本目录**（终端产物）。

---

## 一、文件夹概述与在整体流程中的位置

### 上游（输入来源）

本目录内容由 `Run_5_fk_exclude_false_positive/` 下的脚本产生，三者共享相同上游：

| 输入数据 | 来源路径 | 用途 |
| --- | --- | --- |
| 模板库表 | `Output_0_Template_library/Template_library.csv` | `infile_name→plot_name` 映射、`t_P_sec/t_S_sec`、`plot_order` |
| 模板波形 | `Output_0_Template_library/Template_npy_files/template_*.npy` | 经 `Read_template` 读入并带通滤波，用于重算 `CCs_f` |
| 叠加互相关 SCCs | `Output_1_SCCs_and_MAD/SCCs_h5/`（10 分钟切片 h5） | 画长/短时程 SCCs 曲线、算 STA/LTA |
| MAD 平均字典 | `Output_1_SCCs_and_MAD/MAD_arrays/.../MAD_Average_dict.pkl` | 换算触发阈值为 `Threshold_level × MAD`，计算 `CCs_s_trig_ofMAD` |
| 触发点（核心） | `Output_2_Triggered_SCCs_points/level_20/<template>/CCs_trig_*.pkl` | 每个触发点的 `t_trig/t_left/t_right/CCs_s_trig/max_stalta` 等 |
| 连续 DAS 原始数据 | 80 Hz 归档 `DATA_DEC_80Hz_16m_SORTED/`，默认位置 `IN_DAS_data/continuous_scan_1h/`（外部数据，`Read_DAS_data` 按时间寻址） | 在触发时刻重算逐通道互相关矩阵 `CCs_f`，画 waterfall |

### 下游（输出去向）

**无任何其它脚本读取本目录**，本目录是整个流程的终端诊断/展示分支，产物供人工判读或作为论文配图，不进入后续编目。

## 二、子目录结构与产生脚本

本目录下有两个有产物的子目录（`2_CCs_ZLCC/` 不存在，对应脚本未产出结果）：

### `1_CCs_fk_spec/`

由 `Run_5_fk_exclude_false_positive/1_CCs_fk_for_trig_points.py`【主线脚本】产生。

**核心判别量**：2D f-s（频率-慢度）振幅谱。对落在指定相关值/STA-LTA 区间的触发点，重算逐通道互相关矩阵 `CCs_f`，经 `spectrum.Calculate_fk_amplitude_spectrum` 计算振幅谱，输出多面板诊断图（波形 waterfall + SCCs + STA/LTA + CCs 矩阵 + f-s 谱）。

**目录内容**：

- `config.json`：记录该次运行的所有参数与路径，写在子目录根（注意：记录的 `dir_byPara` 可能与实际产出的参数子目录名不一致，以磁盘子目录名为准）。
- `kur1_12_C0.1_1_win0.5_0.5/`：17 张 PNG（I1×3, I2×4, K1×5, K2×5），为实际产出结果。

### `3_CCs_kurtosis_example_for_paper/`

由 `Run_5_fk_exclude_false_positive/3_CCs_kurtosis_example_for_paper.py`【出图脚本】产生。

**核心判别量**：Kurtosis（STA/LTA）峰值。论文配图版，精修字体/排版/相对时间轴，右侧面板展示放大窗内的 STA/LTA 曲线及触发窗内局部峰值（绿色星）。

**目录内容**：

- `config.json`：记录该次运行参数（`kur20_1000_C0.03_1_win1.5_1.5`）。
- `kur20_1000_C0.03_1_win1.5_1.5/`：25 张 PNG（5 模板各 5 张），高峰度示例，为脚本当前参数的正式产出。
- `kur1_10_C0.03_0.1_win1.5_1.5/`：25 张 PNG（5 模板各 5 张），低相关/低峰度示例，改参后另一批产出，与高峰度子目录构成真/假阳性对照。

## 三、参数子目录命名规律

```text
kur{kur0}_{kur1}_C{C0}_{C1}_win{winL}_{winR}/
例: kur20_1000_C0.03_1_win1.5_1.5/
```

| 字段前缀 | 含义 | 来源参数 |
| --- | --- | --- |
| `kur<a>_<b>` | STA/LTA（"峰度"）筛选区间 [a, b] | `kurtosis_range` |
| `C<lo>_<hi>` | 叠加相关值 `\|CCs_s_trig\|` 筛选区间 [lo, hi] | `C_trig_range` |
| `win<L>_<R>` | 触发时刻左右数据读取窗长（秒） | `Search_win` |

（若为脚本 2 产出，子目录名还追加 `_Z{Zl}_{Zr}_p{p}_q{q}` 表示群组相似度滑窗与分位数参数。）

## 四、输出 PNG 命名规律

```text
<plot_name>_<|CCs_s_trig|>_<CCs_s_trig_ofMAD>_<YYYYMMDD_HHMMSS_ffffff>.png
例: Temp_I1_0.1136_50.3_20240511_135123_025000.png
```

各字段含义（已据脚本代码与 `Template_library.csv` 核实）：

| 字段 | 示例 | 含义与单位 |
| --- | --- | --- |
| `plot_name` | `Temp_I1` | 模板展示名，来自 `Template_library.csv` 的 `plot_name` 列，**不是慢度或方位角** |
| `\|CCs_s_trig\|` | `0.1136` | 该触发点叠加互相关值的绝对值，4 位小数，无量纲（相关系数） |
| `CCs_s_trig_ofMAD` | `50.3`、`-51.5` | 相关值除以该模板 MAD 后的倍数（带符号，负号表示反相关），1 位小数，无量纲 |
| 时间戳 | `20240511_135123_025000` | 触发时刻 `t_trig`，精确到微秒（`%Y%m%d_%H%M%S_%f`） |

**模板 plot_name 映射**（来自 `Template_library.csv`）：

| plot_name | infile_name | 对应事件 |
| --- | --- | --- |
| Temp_K1 | template_10_80Hz | 2024-05-30 Mw2.4 |
| Temp_K2 | template_0423_80Hz | 2024-04-25 Mw2.5 |
| Temp_K3 | template_8_80Hz | 2024-05-10 Mw4.1 |
| Temp_I1 | template_20_80Hz | 2024-05-11 Mw3.1 |
| Temp_I2 | template_0425_80Hz | 2024-04-25 Mw3.0 |

## 五、术语澄清

目录名前缀 `kur*`、脚本参数 `kurtosis_range`、图标题中的 "Kurtosis"，均指**未归一化中心化 STA/LTA**（由 `sta_lta_centred_unnorm` 计算，sta=0.5s, lta=1.5s），是衡量波形突发性/尖锐度的指标，**不是统计学意义上的四阶矩峰度**。
