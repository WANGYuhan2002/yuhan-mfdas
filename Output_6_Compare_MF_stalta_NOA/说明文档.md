## 一、目录角色

本目录是整条 MF 流水线的**最终评估/对比输出目录**，存放三套地震目录（MF / STA-LTA / NOA 官方）互相对齐、打标签后的结果 CSV，以及三目录探测能力对比图。由 Run_6 产生，不被其他 Run_ 读取，是流水线终点。

**上游（输入来源，由 Run_6 脚本消费后写入本目录）**：

| 数据 | 路径 | 产生者 |
|------|------|--------|
| MF 最终地震目录 | `{PROJECT_ROOT}/Output_4_Classified_bySCCs_cleaned_overlaps_withKurtosis/level_20/MagRegression/Events_classified_Real_Mag.csv` | Run_4 系列 |
| NOA 官方目录（IMS 1.0） | `{PROJECT_ROOT}/IN_NOA_cata/200km_distance/IMS_20240425_20240623_263.txt` | 外部输入（希腊 NOA） |
| STA/LTA 目录 | `IN_STALTA_cata/sta_lta_catalog.csv`（`stalta_clustering/.../sta_lta_catalog.csv` 的副本） | 独立 STA/LTA 项目（外部数据依赖；在 Zenodo 存档里，GitHub 版不含） |
| 模板库 | `{PROJECT_ROOT}/Output_0_Template_library/Template_library.csv` | Run_0 |
| 手工插图（嵌入图） | `insert_fig.png` 与 `insert_fig_flat.png`（本目录根目录下） | 手工准备，非脚本生成，须随附 |

## 三、CSV 文件字段说明

### stalta_catalog_enriched.csv（制表符分隔，约 7251 行）

**产出**：Run_6 脚本 1（`1_label_STALTA_with_template_plus_NOAeq.py`）。
**消费**：Run_6 脚本 3、4。

基础来源：STA/LTA 原始触发目录，时间窗筛选后约 7251 条事件。

**原始列（来自 `sta_lta_catalog.csv`）**：

| 列名 | 含义 | 单位/说明 |
|------|------|-----------|
| `Unnamed: 0` | 原始行索引 | 整数 |
| `peak_time` | STA/LTA 触发峰值时刻 | UTC |
| `peak_amp` | 触发峰值振幅 | 原始 DAS 应变率 |
| `peak_score` | STA/LTA 比值得分 | 无量纲 |
| `peak_dist` | 触发峰值空间偏移 | 文件中均为 0 |
| `max_amp_mean` | 均值振幅 | — |

**脚本 1 追加列（时间最近邻匹配）**：

| 列名 | 含义 | 单位/说明 |
|------|------|-----------|
| `noa_match_flag` | 是否在 3 s 内匹配到 NOA 目录 | `True`/`False`；全文件约 514 条为 True |
| `noa_time_diff_s` | 与最近 NOA 地震的时间差 | 秒；未匹配为 NaN |
| `noa_magnitude` | 匹配到的 NOA 震级（ML） | 未匹配为 NaN |
| `noa_latitude` | 匹配到的 NOA 震源纬度 | 度 |
| `noa_longitude` | 匹配到的 NOA 震源经度 | 度 |
| `noa_distance_km` | NOA `STA_distance`（度）× 111 换算为 km | km |
| `mf_match_flag` | 是否在 2 s 内匹配到 MF 检测 | `True`/`False`；全文件约 4353 条为 True |
| `mf_time_diff_s` | 与最近 MF 检测的时间差 | 秒；未匹配为 NaN |
| `mf_template_name` | 匹配到的 MF 模板名 | 未匹配为 `unmatched` |
| `mf_real_mag` | 匹配到的 MF 回归震级（`Real_Mag`） | 未匹配为 NaN |
| `mf_sccs` | 匹配到的 MF 叠加互相关值（`CCs_s_trig`） | 无量纲，负值正常 |

---

### noa_catalog_labeled.csv（制表符分隔，约 893 行）

**产出**：Run_6 脚本 2（`2_label_NOA_with_template_and_detectByMForNot.py`）。
**消费**：Run_6 脚本 3、4。

基础来源：NOA IMS 文件经 `extract_station_info(file, 'FSK')` 解析，按 `EQ_time` 去重，时间窗筛选后约 893 条独立地震事件。

**NOA 解析列**：

| 列名 | 含义 | 单位/说明 |
|------|------|-----------|
| `EQ_time` | 发震时刻 | UTC |
| `EQ_latitude` | 震源纬度 | 度，WGS84 |
| `EQ_longitude` | 震源经度 | 度，WGS84 |
| `EQ_depth` | 震源深度 | km |
| `EQ_magnitude` | NOA 震级（ML） | 无量纲 |
| `STA_name` | 台站名（固定为 `FSK`） | — |
| `STA_distance` | 震中距（**注意：单位为度**，脚本 4 中乘 111 转换为 km） | 度 |
| `STA_azimuth` | 方位角 | 度 |
| `STA_phase` | 震相类型（如 `P_1`、`S_2`） | — |
| `STA_arrival_time` | FSK 台站观测到时 | UTC |

**脚本 2 追加列**：

| 列名 | 含义 | 单位/说明 |
|------|------|-----------|
| `template_region` | 所属 MF 模板区域名（如 `template_10_80Hz`）；距所有模板中心均 >8 km 时为 `outside_all_templates` | — |
| `dist_to_template_center_km` | 震源到最近模板中心的测地线距离 | km |
| `is_detected_by_mf` | 该 NOA 地震是否被 MF 检测到（时间容差 3 s 且空间 ≤ 7 km） | `True`/`False`；全文件约 251 条为 True |
| `mf_detection_time_diff_s` | MF 检测时刻与 NOA `STA_arrival_time` 的时间差 | 秒；未匹配为 NaN |
| `mf_template_name` | 成功检测时对应的 MF 模板名 | 未匹配为 `unmatched` |

## 五、脚本 4 两版本布局差异

| 差异项 | 原版（`4_detection_power.png`） | 横版（`4_detection_power_flat_layout.png`） |
|--------|--------------------------------|---------------------------------------------|
| 图幅 | 20×21 英寸 | 30×21 英寸（更宽） |
| 面板布局 | 震级-距离图跨顶行；插图左下；地图右下 | 地图占左侧全高；震级-距离图右上；插图右下 |
| 嵌入插图 | `insert_fig.png` | `insert_fig_flat.png` |
| 地图范围 | `lon[18.9,22.7] lat[36.5,40.5]`（更大） | `lon[19.95,22.2] lat[36.7,39.5]`（聚焦 Kefalonia） |
| STA/LTA 地图标记色 | 白色星 | 蓝色星 |
| scaling_factor | 30 | 70（符号更大） |

两版本数据逻辑完全等价，二选一使用。
