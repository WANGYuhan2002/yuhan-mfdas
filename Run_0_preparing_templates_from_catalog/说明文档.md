## 二、本文件夹角色

本文件夹是模板库制作的**第一阶段**：从 NOA 地震目录与 DAS STA/LTA 检测结果出发，经 SNR/震级控制、事件间互相关、相似事件去重，筛出互不相似、高信噪比的候选模板事件（`dup_temp_df.csv`）。模板波形 `.npy` 实际由下游 `Output_0_Template_library` 的脚本 2 产出；`Output_0` 同时完成最终人工精选与字段补充，形成 `Template_library.csv`。

## 四、脚本逐个说明

### 脚本 1：`1_SNR_Mag_control_find_NOAeq_SatisfyStalta_OverlapUseTime.py`

- **作用**：把 DAS STA/LTA 检测事件与 NOA 目录按到时做时间匹配，筛出「既被 STA/LTA 检测到、又在 NOA 目录里、震级≥2.0、SNR 足够高」的事件，作为候选模板第一稿。
- **输入**：
  - `threshold_100_trigNO_100_sta0.3s_lta3s/sta_lta_catalog.csv`（列：`peak_time, peak_amp, peak_score, peak_dist, max_amp_mean`；`peak_amp ≈ SNR²`）。
  - NOA IMS 文件（经 `extract_station_info` 解析，台站 FSK）。
  - 关键参数：`magnitude_cut=2.0`；`SNR_cut_again=30`（对应 `peak_amp_cut ≥ 900`）；`as_one_ev_interval=10`（时间差 ≤10 s 视为同一事件）；`freq_band=[8,20]`；通道范围 8.3–14 km。
- **输出**（写入 `Output_1_Find_NOAeq_Mag2.0_10sec_SNR30_100km/`，目录名由参数决定）：
  - `matched_df.csv`（**tab 分隔**；列：`idx, peak_time, peak_amp, peak_score, max_amp_mean, match_or_not, time_diff_sec, STA_arrival_time, STA_distance, STA_azimuth, EQ_time, EQ_latitude, EQ_longitude, EQ_depth, EQ_magnitude`）
  - `config.json`、`Detectable_STALTA_in_FSK_EQs.png`、`Check_time_diff_histogram.png`。
- **核心逻辑**：读 STA/LTA 目录 → 按 SNR/时间窗过滤 → 读 NOA 目录 → 对每个 STA/LTA 事件找时间最近 NOA 事件（差 ≤10 s 标 `match_or_not=1`）→ 画图并保存匹配表。
- **依赖 functions**：`readers`、`plot.Ticks_xaxis_day_or_hour`、`extract_station_info.extract_station_info`。出图需 geopandas/cartopy/contextily/adjustText。

### 脚本 2：`2_Comp_corr_between_events_v6.py`

- **作用**：对脚本 1 选出的候选事件两两计算 DAS 波形的叠加归一化互相关最大值，得到事件间相关矩阵与时间偏移矩阵。
- **输入**：
  - `Output_1_.../matched_df.csv`（脚本 1 产物，取 `peak_time` 列）。
  - 连续 DAS 数据。
  - 参数：`freq_band=[8,20]`；窗口 `t_left=10s, t_right=20s, t_pad=10s`；`fs=80`；通道 8.3–14 km；并行 `n_workers=20, chunk_size=500, dtype=float32`。
- **输出**（写入 `Output_2_Corr_movmax/`）：
  - `correlation_matrix.npy`（`(N,N) float32`，带符号归一化相关峰值，对角≈1）
  - `offset_matrix.npy`（`(N,N) int32`，单位=采样点，反对称）
  - `config.json`、`correlation_matrix_abs.png`、`offset_matrix.png`、`offset_matrix_abs.png`。
- **核心逻辑**：所有候选事件波形读入共享内存 → 预计算滑动标准差 → `ProcessPoolExecutor` 并行对每对 `(i,j)` 做 FFT 互相关（`signal.fftconvolve`）、按通道归一化求和、取绝对值最大处 → 填充对称矩阵并保存。
- **依赖 functions**：`cluster.read_DAS_span`（核心读数+带通）、`cluster.simple_corr_coef_*`、`norm_the_flattened_DATA`、`readers`、`plot`、`load_das_h5_PE2024`。

### 脚本 3：`3_Similarity_control_delete_similar_eqs.py`

- **作用**：用相关矩阵做 DBSCAN 聚类，把波形相似的事件归为一簇，每簇只保留震级最大的一个（加上全部孤立"噪声"事件），从而删掉重复/相似地震，得到去重候选模板表 `dup_temp_df.csv`。
- **输入**：
  - `Output_1_.../matched_df.csv`（脚本 1，tab 分隔）。
  - `Output_2_Corr_movmax/correlation_matrix.npy`（脚本 2）。
  - 参数：DBSCAN `eps=0.90, min_samples=2`（距离矩阵 `D=1−|R|`，precomputed）。
- **输出**（写入 `Output_3_Delete_similar_eqs/`）：
  - `dup_temp_df.csv`（**★ 下游关键产物**，去重后候选模板表，逗号分隔）
  - `matched_df_with_clusters.csv`（matched_df + `cluster` 列）
  - `cluster_labels.npy`（每事件簇标签，-1=孤立）、`tsne_coordinates.npy`（t-SNE 坐标，仅可视化）、`cluster_data.pkl`
  - `corr_matrix_dup_temp.npy`（`(M,M) float32`，去重模板子相关矩阵，实测 12×12）
  - `config.json`、`dbscan_clustering_plot.png`、`corr_initial_duplicate_templates_map.png`。
- **核心逻辑**：`D=1−|R|` → DBSCAN → t-SNE → 每簇取 `EQ_magnitude` 最大行+全部 `cluster==-1` 行 → 存去重表 + 子相关矩阵 + 出图。
- **依赖 functions**：`readers`、`plot`、`extract_station_info`；sklearn DBSCAN/TSNE；geopandas/cartopy/contextily/adjustText。

### 脚本 3_1：`3_1_Similarity_control_delete_similar_eqs_plot_for_paper.py`（出图，可忽略）

- **作用**：脚本 3 的论文出图版，聚类/选模逻辑相同，但专产排版精美的双联图供论文使用。
- **输入**：同脚本 3，但默认指向 `Output_1_Find_NOAeq_Mag2.0_10sec_SNR30_100km/`。
- **输出**（写入 `Output_3_Delete_similar_eqs_for_paper/`）：
  - `correlation_matrix_final_templates.npy`（`(M,M) float32`，等价 `corr_matrix_dup_temp.npy`）
  - `cluster_data.pkl`、`config.json`
  - `DBSCAN_clustering_and_map_summary.png`（论文双联图）。
  - **注意**：此脚本**不写** `dup_temp_df.csv`、`matched_df_with_clusters.csv`、`cluster_labels.npy`、`tsne_coordinates.npy`，不可替代脚本 3 为下游提供去重表。
- **依赖 functions**：同脚本 3（路径通过 bootstrap 正确指向本 release functions）。

### 脚本 4：`4_Produce_templates_from_EQs.py`

- **作用**：读取去重模板表，从连续 DAS 数据中切取每个候选模板波形，并画一张「所有模板 waterfall + 相关矩阵 + 地图」总览图。当前 release 中 `save_as_temp_or_not=0`，模板 `.npy` 的实际落地在下游 `Output_0_Template_library` 完成。
- **输入**：
  - `Output_3_Delete_similar_eqs/dup_temp_df.csv`（脚本 3 产物）。
  - `Output_3_Delete_similar_eqs/corr_matrix_dup_temp.npy`。
  - 连续 DAS 数据。参数：`peak_time_left_pad=8s, right_pad=42s`（模板时窗 50 s）；`freq_band=[5,20]`（仅可视化）；通道 8–14 km。
- **输出**（写入 `Output_4_Produce_templates/`）：
  - `ALL_templates_waterfall_map.png`（总览拼版图）
  - `config.json`（参数快照，`save_as_temp_or_not=0`）。
  - 模板 `.npy` 文件在本脚本中**未实际产出**（存盘逻辑 `save_as_temp_or_not=0`），波形 npy 由 `Output_0_Template_library/2_check_again_map_Produce_templates_from_EQs.py` 产出。
- **依赖 functions**：`plot`、`das_mffi_io`、`load_das_h5_PE2024`、`pydas_readers`、`compute_correlation.preprocess`。

## 五、脚本执行顺序与数据流

```text
[外部输入] sta_lta_catalog.csv + PARAs.pkl   (上游 STA/LTA 检测，本文件夹只读)
[外部输入] ../IN_NOA_cata/100km_distance/IMS_20240425_20240623_319.txt
[外部输入] IN_DAS_data/continuous_scan_1h/  (80 Hz 归档 DATA_DEC_80Hz_16m_SORTED/)
            │
            ▼
  脚本 1  1_SNR_Mag_control_find_NOAeq...
            │  → Output_1_Find_NOAeq_*/matched_df.csv (tab分隔, N个候选事件)
            ▼
  脚本 2  2_Comp_corr_between_events_v6
            │  → Output_2_Corr_movmax/correlation_matrix.npy, offset_matrix.npy
            ▼
  脚本 3  3_Similarity_control_delete_similar_eqs    ──(出图分支)──►  脚本 3_1 ..._plot_for_paper
            │  → Output_3_Delete_similar_eqs/                        → Output_3_Delete_similar_eqs_for_paper/
            │      dup_temp_df.csv ★                                     DBSCAN_clustering_and_map_summary.png (论文图)
            │      corr_matrix_dup_temp.npy
            ▼
  脚本 4  4_Produce_templates_from_EQs
            │  → Output_4_Produce_templates/ALL_templates_waterfall_map.png
            │  （模板 .npy 未在此产出）
            ▼
[下游] Output_0_Template_library（人工精选 → 复核 → 产 npy → 补字段 → Template_library.csv）
```

执行顺序严格为 **1 → 2 → 3 → 4**；3_1 与 3 可并行运行（仅出论文图），但不替代 3。
