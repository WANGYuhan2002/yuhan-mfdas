## 二、脚本逐个说明

### 脚本 1：`1_Trigger_SCCs_eachTemp_byMADandLevel_constThres_Parallel.py`（并行版，主线）

- **作用：** 多进程对每模板每 10 分钟 SCCs 切片做 `MAD×level` 触发，并为每个触发点算 SCCs 上的 STA/LTA 最大值 `max_stalta`，写 pkl。
- **路径自给自足：** 脚本顶部有 `# === dasmf path bootstrap ===` 引导块，IO 路径均写为 `f"{PROJECT_ROOT}/..."` 形式。
- **输入：**
  - SCCs/RAWCCs：`{PROJECT_ROOT}/Output_1_SCCs_and_MAD/SCCs_h5/` → `Read_CCs_stack_h5`。
  - MAD：`{PROJECT_ROOT}/Output_1_SCCs_and_MAD/MAD_arrays/.../12:00:00/MAD_Average_dict.pkl` → `load_pkl`。
  - 关键参数：`Threshold_level=50`、`Minimal_event_interval=3s`、`fs=80`、5 模板 `template_0423/0425/10/8/20_80Hz`、`2024-04-24 10:20 ~ 2024-06-22 17:10`、`t_delta=10min`、`num_cpus=10`、`sta_len=0.5s`、`lta_len=1.5s`、`search_win=[0.6,0.2]s`。
- **输出：** `{PROJECT_ROOT}/Output_2_Triggered_SCCs_points/level_50/{template}/CCs_trig_*.pkl` + 该 level 的 `config.json`。
- **核心处理逻辑：**
  1. `main()` 建目录、存 `config.json`；外层按模板循环，`Pool.imap_unordered` 并行跑 `process_segment`。
  2. `process_segment`：若 pkl 已存在则跳过返回已存触发数。
  3. **读宽窗：** 读取 `[t_start - lta_len, t_end + sta_len]` 的 `CCs_s_wide, RAWCCs_s_wide`，再裁回 `[start_index:end_index]` 得 `CCs_s, RAWCCs_s`（避免 STA/LTA 在切片边界的瞬态）。
  4. **算 STA/LTA：** 对 `CCs_s_wide` 整段调 `sta_lta_centred_unnorm(·, sta_len*fs, lta_len*fs)`，同样裁剪对齐得 `sl_unnorm`。
  5. **触发：** `Trigger_with_MADarray(...)` 得 `CCs_s_trig, t_trig, t_left, t_right, width_trig`（阈值 = MAD×level，按 `Minimal_event_interval` 去近邻）。
  6. 算样点索引 `idx_t_trig`，越界过滤；取 `RAWCCs_s_trig`。
  7. 每触发点 `[t_left,t_right]` 窗内取 `|RAWCCs|` 最大 → `max_RAWCCs/t_arg_max`（空窗填 `np.nan`）。
  8. **算 `max_stalta`：** 每触发点在 `[idx-0.6·fs, idx+0.2·fs]` 窗内取 `sl_unnorm` 最大值；空窗填 `np.nan`。
  9. 算 `SCCs_of_MAD = CCs_s_trig / MAD`；组 `OUT_dict`（10 个键）→ `write_pkl`。
- **输出 pkl 字段（10 个键）：** `t_trig, CCs_s_trig, RAWCCs_s_trig, width_trig, t_left, t_right, SCCs_of_MAD, max_RAWCCs, t_arg_max, max_stalta`。
- **依赖 functions 模块：** `readers.Read_CCs_stack_h5 / write_pkl / load_pkl`、`trigger.Trigger_with_MADarray`、`stalta.sta_lta_centred_unnorm`。
- **备注：** 「kurtosis」是历史口语命名，代码实现的判据是 SCCs 上的 STA/LTA 比值，并非数学峰度。`constThres` 指分段常数阈值：`Trigger_with_MADarray` 按 MAD 时间网格分段，每段阈值 = `MAD_grid[ii] × Threshold_level`（段内恒定）。

### 脚本 2：`1_Trigger_SCCs_eachTemp_byMADandLevel_constThres.py`（非并行版，旧版/可忽略）

- 串行双 for 的早期原型，路径全硬编码到旧版项目目录，`Threshold_level=40`，MAD 用 `4:00:00` 窗，模板列表是旧命名 `temp_0…temp_12`（13 个），`freq_band=[5,20]`。
- **没有任何 STA/LTA / `max_stalta` 逻辑**，输出 pkl 字段最少（9 键），不是当前 Output_2 数据的生产者。

### 脚本 3：`2_Show_Trig_TimeHisto_SCCsPoints.py`（出图，可忽略）

- 读已触发 pkl，画各模板触发事件随时间直方图（bin=1h）和全模板触发点散点叠加图，叠加外部 STA/LTA 目录参考。
- **外部数据依赖：** STA/LTA 参考目录从包内 `IN_STALTA_cata/sta_lta_catalog.csv` 读取（原为外部 STA/LTA 工程的 `stalta_clustering/Output_1_STALTA_catalog_v1/...`），运行前须确认该文件存在（在 Zenodo 存档里，GitHub 版不含）。另依赖 `pydas_readers`（外部包）和 `load_das_h5_PE2024`。
- **输入：** 触发 pkl 目录 → `Read_CCs_trig_pkl`；`Template_library.csv`；外部 `sta_lta_catalog.csv`；MAD 字典（画阈值横线）。
- **输出：** `Output_2_Triggered_SCCs_points/show_trigger/level_XX/...png`（直方图与触发点散点图）。

## 三、执行顺序与依赖关系

```
Output_1_SCCs_and_MAD/{SCCs_h5, MAD_arrays}
        │
        ▼
[脚本1: 1_..._Parallel.py]   ← 主线：MAD×level 触发 + 算 max_stalta
   读 SCCs_h5(宽窗) + MAD_Average_dict.pkl → 对 SCCs 算 STA/LTA
        │  写出（10 键 pkl）
        ▼
   ../Output_2_Triggered_SCCs_points/level_{N}/{template}/CCs_trig_*.pkl + config.json
        │
        ├──►[脚本3: 2_Show...py]  读 pkl 出图（show_trigger/），可选人工检查
        │
        └──► 下游：Run_3 → Run_4（强依赖 max_stalta） → Run_5 → Run_6
```

先有 Output_1，再运行脚本 1（主线），脚本 3 仅用于人工检查，与下游无强前置关系。

## 四、数据说明

本文件夹脚本写到 `../Output_2_Triggered_SCCs_points/`（详见该文件夹说明文档），当前落盘数据均由本文件夹并行版主线脚本产出。

**输出 pkl 核心字段含义：**

| 键 | 含义 |
|---|---|
| `t_trig` | 触发时刻（UTC） |
| `CCs_s_trig` | 触发点处 SCCs 值（约 -1~1） |
| `RAWCCs_s_trig` | 触发点处原始互相关值（未归一化） |
| `width_trig` | 触发脉冲宽度（timedelta） |
| `t_left / t_right` | 触发窗左/右边界时刻 |
| `SCCs_of_MAD` | `CCs_s_trig / MAD`，绝对值 ≥ level 才触发 |
| `max_RAWCCs` | `[t_left,t_right]` 窗内 `\|RAWCCs\|` 最大值（带符号）；空窗 NaN |
| `t_arg_max` | `max_RAWCCs` 对应时刻 |
| `max_stalta` | **核心**：`search_win` 窗内 SCCs 的 STA/LTA 比值最大值（脉冲尖锐度）；空窗 NaN |

`max_stalta` 是本变体的核心附加字段，下游 Run_4 强依赖此键做假阳性过滤。
