## 一、文件夹概述与在整体流程中的位置

**作用**：本文件夹是模板匹配（matched filter, MF）编目流程的**去重叠+分类+估震级阶段**，采用「峰度/STA-LTA 质量判据」（代码变量名 `max_stalta`，阈值=10）筛除假触发，然后做多模板去重叠（assign overlaps），再估震级，输出最终地震目录。

**上游输入**（均在 `PROJECT_ROOT/` 下，路径由 `dasmf path bootstrap` 自动定位）：
- `Output_0_Template_library/Template_library.csv` 及 `Template_npy_files/`：模板库（5 个模板）及元信息（`self_CC`、`amp_max_mean`、`amp_log_mean`、`t_P_sec`/`t_S_sec`、`plot_order`、`plot_name` 等）。
- `Output_1_SCCs_and_MAD/SCCs_h5/`：连续叠加互相关 SCCs，按 10 分钟切片存 h5。
- `Output_1_SCCs_and_MAD/MAD_arrays/.../12:00:00/MAD_Average_dict.pkl`：各模板平均 MAD 值（触发阈值基准）。
- `Output_2_Triggered_SCCs_points/level_20/`：触发点 pkl，每条记录含 `max_RAWCCs`、`t_arg_max`、`max_stalta`（由 Run_2_kurtosis 版本在触发阶段算好存入）。这是 Run_4 能用 kurtosis 判据的前提。
- `Output_3_Trig_PeakAmp/level_20/Trig_MAX_amp_df.csv`：每条触发的 DAS 峰值振幅（`amp_max_mean`、`amp_log_mean`）。**注意：2b 会读它，但仅用于可选的振幅分支 `Quasi_Mag_Amp` 与对照图；最终震级 `Real_Mag` 用 `max_RAWCCs` × 模板自身振幅标定，不依赖此逐事件振幅**（即 Output_3/Run_3 非最终震级关键路径，详见下方 2b 节及 `Run_3/.../说明文档.md`）。
- `IN_NOA_cata/200km_distance/IMS_20240425_20240623_263.txt`：NOA/IMS 目录（台 FSK），用于把准震级 Quasi_Mag 标定到真实 ML。

**本文件夹的产物去向**：
- 主输出写到 `Output_4_Classified_bySCCs_cleaned_overlaps_withKurtosis/`（对应 Output_4）。
- 仅 1b 的产物写在本文件夹内 `Output_1b_decide_kurtosis/level_20/`（定阈值分析，不进入主数据流）。

**下游消费者**：
- `Run_6_get_and_compare_STALTAinMF_NOAinTemp_MF/` 读取 Output_4 的 `Events_classified_Real_Mag.csv`，把 MF 目录与 STA/LTA、NOA 目录三者对比评估检测能力（最终主线下游）。

整体链条：
`Output_2(kurtosis版触发) + Output_3(峰值振幅) + Output_0(模板库) + Output_1(MAD)` → **2a/2b** → `Output_4/level_20/MagRegression/Events_classified_Real_Mag.csv` → **出图脚本(3/4/5)** 与 **Run_6（对比评估）**。

## 二、脚本逐个说明

> 共同硬编码常量：`fs=80`、`freq_band=[8,20]`、5 个模板（`template_0423_80Hz / template_0425_80Hz / template_10_80Hz / template_8_80Hz / template_20_80Hz`）、时间窗 `2024-04-24 10:20:00 ~ 2024-06-22 17:10:00`、`level_20`（阈值=20×MAD）。

### 1_check_kurtosis_CCs.py —— 触发快照可视化（探索/质检）

- **一句话**：抽取若干已分类触发事件，画 4 联子图（模板瀑布、数据瀑布、SCCs 曲线+阈值、RAWCCs 曲线），人工核对触发是否真实。
- **输入**：`Output_4_Classified.../level_20/Events_classified_AllTemp.csv`（读 Output_4）、`Output_1_SCCs_and_MAD/SCCs_h5/`、MAD pkl、模板库。
- **输出**：PNG 到 `Output_6.../1_Check_RAWCCs_ok_wtf_snapshots/level_20/`（写 Output_6）。
- **备注**：输入来自 Output_4、输出写到 Output_6，与本支主输出 Output_4 不一致，属遗留路径；不进入主数据流。

### 1a_kurtosis_statitics.py —— kurtosis 与 C 联合统计（探索）

- **一句话**：统计 `max_stalta` 与触发 SCC 值 C 的联合分布，画散点/计数矩阵/P-R 曲线，辅助理解 kurtosis 判据取舍。
- **输入**：`Output_2.../level_20/` 触发 pkl、模板库、MAD。
- **输出**：3 张 PNG + `config.json`。
- **备注**：整脚本硬编码到 `matched_filter_v6` 路径，与本 release 无关联；纯探索，可忽略。

### 1b_decide_kurtosis_by_collapsed_no.py —— 扫 kurtosis 阈值看事件数变化（方法依据）

- **一句话**：把 `max_stalta` 阈值从 0 扫到 40（步长 0.2），统计每个阈值下过滤前/过滤后/去重叠后事件数，据此选定 kurtosis 阈值=10。
- **输入**：`Output_2.../level_20/` 触发 pkl、模板库、MAD（均 PROJECT_ROOT 下）。
- **输出**（唯一写在本文件夹内的数据）：`Output_1b_decide_kurtosis/level_20/`：

  - `stalta_threshold_analysis.csv`（201 行；行=阈值 0~40 步长 0.2，列=total/各模板的 raw/filtered/collapsed 计数）
  - `total_events_vs_stalta_threshold.png`、`template_events_vs_stalta_threshold_detailed.png`
  - `config.json`（记录 `max_stalta_threshold_chosen=10`）

- **备注**：是「怎么定 kurtosis 阈值」的实验记录。结论 `max_stalta_threshold=10` 被 2a 主线采用。

### 2a_Classification_byCCs_with_kurtosis.py —— 【主线数据生产，核心】

- **一句话**：先用 kurtosis 判据（`max_stalta>10`）过滤假触发，再对 5 个模板的触发点合并做去重叠，输出最终分类事件表。
- **输入**：`Output_2.../level_20/` 触发 pkl、模板库、MAD pkl。
- **输出**（写到 `Output_4.../level_20/`）：

  - `Events_classified_AllTemp.csv`
  - `Events_classified_AllTemp_addRAWCCs.csv`（与前者内容字节级相同，历史命名遗留）
  - `config.json`（全部参数/路径的权威记录）

- **核心逻辑**：`Read_Collapse_group_df` 读全部模板触发（含 `max_RAWCCs/max_stalta`）→ mask `max_stalta>10` 删低质量触发 → `Collapse_with_MAX_CCs(IN_one_event_interval=2.5)` 按 2.5s 时间窗去重叠，保留同组内 `|CCs_s_trig_ofMAD|` 最大一条（`Belong_or_not=1`）→ 保存。
- **实测**：共 17,326 条检测（其中 17,325 条在截至 2024-06-22 16:15 的分析时窗内；跨模板合并重叠检测后为 17,263 条，即 `Belong_or_not==1`）。

### 2b_Est_Mag_with_GR_law_check.py —— 【主线震级估计】

- **一句话**：把 `max_RAWCCs` 通过 `self_CC` 与 `amp_max_mean` 标定成准震级，再用 NOA/IMS 真实 ML 做线性回归得到 Real_Mag，并出 G-R 律图。
- **输入**：`Output_4.../level_20/Events_classified_AllTemp_addRAWCCs.csv`、`Output_3.../Trig_MAX_amp_df.csv`（振幅）、模板库（取 `self_CC/amp_max_mean`）、`IN_NOA_cata/.../IMS_*.txt`（台 FSK）。
- **输出**（写到 `Output_4.../level_20/MagRegression/`）：

  - `Events_classified_Real_Mag.csv`（**最终带震级地震目录**，追加 `amp_log_mean`、`amp_max_mean`、`Quasi_Mag_Amp`、`fac_CC2amp`、`Quasi_Mag`、`Real_Mag`）
  - `Events_with_NOA_Mag/{Template}_Events_with_NOA_Mag.csv`（每模板 NOA 匹配子集，用于标定回归）
  - `Events_with_NOA_Mag/Quasi_Mag_to_NOA_Mag.png`、`GR_law_check/Real_Mag_GR_law.png`、`GR_law_check/Quasi_Mag_GR_law.png`、`max_RAWCCs_vs_peakAmp/max_RAWCCs_vs_peakAmp.png`

- **核心逻辑**：`method='max_RAWCCs'`；逐模板 `fac_CC2amp = amp_max_mean/self_CC`，`Quasi_Mag = log10(|max_RAWCCs × fac_CC2amp|)` → 在 NOA 目录中按模板震源 ±0.05° + 时差 <5s 匹配 → 每模板 ≥3 个匹配才做 `Real_Mag = slope×Quasi_Mag + intercept` 线性回归 → 出 G-R 图。
- **澄清（最终震级用什么 / Run_3 的角色）**：上式里的 `amp_max_mean`、`self_CC` 取自**模板库**（`Template_library.csv`，5 个模板各一个常数，由 Output_0 提供），**不是** Output_3 的逐事件峰值振幅。所以最终 `Real_Mag` 只依赖 `max_RAWCCs` + 模板常数 + NOA 标定。2b 另外读 `Output_3` 的逐事件振幅，仅用来生成**并列备选列** `Quasi_Mag_Amp`（method 若设 `'Amp'` 时才作主估计）和「`max_RAWCCs` vs 峰值振幅」对照图——**这些都不进 `Real_Mag`**。因此 **Run_3/Output_3 在当前最终方案中是可选项**（保留备用，详见 `Run_3/.../说明文档.md`）。

### 4.3 关键含义备注

- `max_stalta`：触发时刻邻域内 STA/LTA 特征函数（`sl_unnorm`）的峰值（在 Run_2_kurtosis 阶段算并存入触发 pkl），代码与图中当作「Kurtosis」判据；越大越像真震，阈值 10 用于筛假触发。

- `Moment = 10^(1.5×(Mw+6.03))` N·m（同上，仅在出图脚本内计算）。
