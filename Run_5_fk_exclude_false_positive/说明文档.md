# Run_5_fk_exclude_false_positive 说明文档

本 release 脚本分类：

- 【主线】`1_CCs_fk_for_trig_points.py`：f-k 分析判别真/假触发，是本文件夹的核心流程脚本。
- 【辅助模块（被主线 import，保留）】`spectrum.py`、`group_similarity.py`：同目录兄弟模块，脚本直接运行时自动在 path 上，无需单独安装。
- 【探索（可忽略，已保留原地）】`2_CCs_ZLCC_for_trig_points.py`：ZLCC/群组相似度方法，探索性分支，未在最终数据上产出结果。
- 【出图（可忽略）】`3_CCs_kurtosis_example_for_paper.py`：论文配图版，展示峰度(STA/LTA)判据，排版精修，可忽略用于流程复现。

> 本文件夹用「f-k 谱」等方法对模板匹配（MF）得到的**触发点**做真/假阳性甄别与可视化展示。读触发点 → 读原始 DAS 数据 → 在触发时刻重新计算逐通道互相关矩阵 `CCs_f` → 从 `CCs_f` 派生 f-k 谱，并把多面板诊断图保存到 `Output_5_CCs_fk/`。
>
> **它不产出新的事件目录或数组，只产出 PNG 图，没有任何下游脚本消费它的输出。**

## 二、脚本逐个说明

### 脚本 1：`1_CCs_fk_for_trig_points.py`【主线】

**一句话作用**：对落在指定相关/峰度区间的触发点，重算逐通道互相关矩阵 `CCs_f`，再做 **f-k（频率-波数 / 频率-慢度）振幅谱**，输出含波形+SCCs+STA/LTA+CCs 矩阵+f-k 谱的多面板诊断图。

**输入**：

- 触发点：`Output_2_Triggered_SCCs_points/level_20/`（经 `Read_Collapse_group_df` 汇总成 `Collapse_group` 表）。
- 模板/SCCs/MAD/DAS 同「上游」表。
- 关键参数（`Config`）：`Threshold_level=20`、`max_stalta_threshold=14`、`kurtosis_range=[1,12]`、`C_trig_range=[0.1,1]`、`Search_win=[0.5,0.5]` 秒、`max_plots_per_template=5`、`fs=80`、`freq_band=[8,20]`、`dx≈16.335 m`、通道距离 `8.3–14 km`。

**输出**：

- PNG → `Output_5_CCs_fk/1_CCs_fk_spec/<dir_byPara>/`，其中 `dir_byPara = kur{kur0}_{kur1}_C{C0}_{C1}_win{L}_{R}/`（如 `kur1_12_C0.1_1_win0.5_0.5/`）。
- `config.json` → 写到 `1_CCs_fk_spec/`（在 `OUTPUT_dir` 根，**不**在 `dir_byPara` 子目录里）。

**核心处理逻辑**：

1. `Read_Collapse_group_df(...)` 把 Output_2 的触发 pkl 读成 DataFrame，含 `t_trig/t_left/t_right/CCs_s_trig/max_stalta`，并加 `Rt_trig`（用模板 S 偏移回推真实发震时刻）、`CCs_s_trig_ofMAD`（相关值/该模板 MAD）。
2. 用 `max_stalta_threshold` 粗筛 + `Collapse_with_MAX_CCs` 做事件去重（仅用于打印统计，未用于出图筛选）。
3. 逐模板用 `mask`（`max_stalta∈kurtosis_range`、`|CCs_s_trig|∈C_trig_range`）选出待画触发点，每模板最多 `max_plots_per_template` 张。
4. 对每个触发点：`Read_template` 读模板 → `Read_DAS_data` 读 `[t_trig-Search_win[0], t_trig+Search_win[1]+模板长]` 的 DAS → `CCs_comp(data,temp)` 得 `CCs_f`（形状 `(时间, 通道)`）。
5. `spectrum.Calculate_fk_amplitude_spectrum(CCs_f, 1/fs, dx)` 得 `(freqs, wavenums, ampspec)`。
6. `event_row_IN_fig_OUTput(...)` 出图并存盘。

**图面板**（左 4 + 右 3）：左=模板 waterfall / 滤波后 DAS waterfall / 长时程 SCCs+阈值 / STA-LTA；右=`CCs_f` 时域矩阵 waterfall / 放大 SCCs / **2D f-s（频率-慢度）振幅谱**（代码里 f-k 版作为注释保留，实际画的是 `pcolormesh`，对数色标）。

**依赖的 functions 模块**：`readers`（`Read_CCs_stack_h5/Read_DAS_data/Read_template/load_pkl`）、`compute_correlation.CCs_comp`、`plot.waterfall_date`、`classify`（`Collapse_with_MAX_CCs/Read_Collapse_group_df`）、`stalta.sta_lta_centred_unnorm`；本地兄弟模块 `spectrum.Calculate_fk_amplitude_spectrum`。

**备注**：真假甄别**没有自动判据/阈值**，只把 f-k 谱画出来供肉眼判断（真地震在 f-k/f-s 谱上沿固定慢度成线状能量，假阳性多为散乱/噪声）。`group_similarity` 被 import 但脚本 1 本身**未**用群组相似度。

### 脚本 2：`2_CCs_ZLCC_for_trig_points.py`【探索（可忽略）】

**一句话作用**：把脚本 1 的「f-k 谱」面板换成 **ZLCC / 群组相似度（Group Similarity）滑动时间序列**——在 `CCs_f` 矩阵上滑窗计算 4 个通道间相似度指标，作为真/假阳性的判别量并出图。

**输入**：与脚本 1 相同的上游数据；额外参数：`Search_win=[1.5,1.5]`、`max_stalta_threshold=10`、`kurtosis_range=[1,10]`、`C_trig_range=[0.1,1]`、`max_plots_per_template=15`；群组相似度参数：`Z_win=[0.15,0.15]` 秒（滑窗半宽）、`Z_p_ratio=0.5`、`Z_q_ratio=0.5`。

**输出**：PNG → `Output_5_CCs_fk/2_CCs_ZLCC/<dir_byPara>/`。**磁盘上 `Output_5_CCs_fk/2_CCs_ZLCC/` 目录不存在** → 该脚本未在最终数据上产出。

**核心处理逻辑**：前半段与脚本 1 相同。差异：调用 `group_similarity.compute_moving_similarity_metrics(CCs_f_calc, config)` 在长窗上滑窗，返回 4 条时间序列（离群相似度、孤独相似度、分位点相似度、平均余弦相似度），出图左 8/右 6 面板。

**依赖的 functions 模块**：与脚本 1 相同，外加本地兄弟模块 `group_similarity`。**不依赖 `spectrum`**。

### 脚本 3：`3_CCs_kurtosis_example_for_paper.py`【出图（可忽略）】

**一句话作用**：**论文出图版**——精修排版/字体/相对时间轴，重点展示「峰度(STA/LTA)」判据：把模板波形、滤波 DAS、SCCs 时间序列、Kurtosis(STA/LTA) 曲线及其在触发窗内的峰值，做成发表级多面板图。

**输入**：与脚本 1 相同上游数据。关键参数（**注意**：`kurtosis_range/C_trig_range` 在脚本中被赋值两次，后一次覆盖前一次，实际生效为 `kurtosis_range=[20,1000]`、`C_trig_range=[0.03,1]`）：`Search_win=[1.5,1.5]`、`kurtosis_win=[0.5,0.2]` 秒、`max_stalta_threshold=10`、`max_plots_per_template=5`。

**输出**：PNG → `Output_5_CCs_fk/3_CCs_kurtosis_example_for_paper/<dir_byPara>/`。磁盘上有两个已产出子目录：`kur20_1000_C0.03_1_win1.5_1.5/`（25 图，高峰度示例）与 `kur1_10_C0.03_0.1_win1.5_1.5/`（25 图，低相关/低峰度示例）。

**核心处理逻辑**：主循环与脚本 1 几乎一致。出图函数重写为论文样式：右侧面板用**相对触发时刻的秒数**坐标（`FuncFormatter`+`FixedLocator`），统一字体大小、`dpi=150`、`bbox_inches='tight'`。注意：脚本调用了 `spectrum.Calculate_fk_amplitude_spectrum` 得 `fk_results`，但**实际出图函数里并没有画 f-k 谱**，该结果被算了未用。

**依赖的 functions 模块**：与脚本 1 相同（含 `spectrum`，仅占位未用于绘图）。**不依赖 `group_similarity`**。

---

### 辅助模块 A：`group_similarity.py`【辅助模块，被主线 import，保留】

**作用**：提供 4 个「群组（通道间）相似度」算法 + 1 个滑窗驱动器。所有相似度基于**列向量（通道）的余弦相似度并取绝对值**。纯计算，无 IO。

**函数**：

- `calculate_top_outlier_masscenter_distance(matrix, p)`：top-p% 离群通道到质心的 `(1-平均余弦距离)`。
- `calculate_loneliest_neighborhood_similarity(matrix, p)`：最孤独 p% 通道与其最佳邻居的平均相似度。
- `calculate_pairwise_similarity_quantile(matrix, q)`：所有通道对余弦相似度的 q 分位点。
- `calculate_average_pairwise_similarity(matrix)`：所有通道对平均余弦相似度（ZLCC 主量）。
- `compute_moving_similarity_metrics(CCs_matrix, config)`：滑窗驱动，返回上述 4 条等长时间序列。

---

### 辅助模块 B：`spectrum.py`【辅助模块，被主线 import，保留】

**作用**：从二维实信号算单边频率的 f-k 振幅谱。

**核心函数** `Calculate_fk_amplitude_spectrum(signal_2d, dt, dx)`：

- 输入 `signal_2d`（时间, 空间）= `CCs_f`；`dt=1/fs`；`dx`=通道间距。
- `fft2` → 取模并按 `Nt*Nx` 归一化 → 波数轴 `fftshift` 居中 → 取 `f≥0` 单边谱（非直流/奈奎斯特处 ×2 恢复物理振幅）。
- 返回 `(freqs, wavenums, ampspec)`：`freqs` 长度 `Nt//2+1`；`wavenums` 长度 `Nx`（居中）；`ampspec` 形状 `(len(freqs), Nx)`。

另含绘图辅助 `plot_fk_spectrum(...)`，当前脚本均未调用。

---

### 术语澄清（重要）

脚本里的 **`max_stalta` / 图上标 "Kurtosis"**，实际来自上游触发表的 `max_stalta` 列，且绘图时用 `sta_lta_centred_unnorm`（未归一化中心化 STA/LTA）重算曲线。**「峰度(kurtosis)」在本文件夹里是 STA/LTA 这一"波形尖锐度/突发性"指标的别称**，并非统计意义上的四阶矩峰度。变量名 `kurtosis_range`、目录前缀 `kur*` 都指 STA/LTA 的取值区间。

## 五、数据与中间数据说明

本文件夹**不产生数组/目录类中间数据，只产生 PNG 图 + config.json**。

### 输出 PNG 命名规律

统一格式（在三脚本主循环中拼接）：

```text
<plot_name>_<|CCs_s_trig|>_<CCs_s_trig_ofMAD>_<YYYYMMDD_HHMMSS_ffffff>.png
例: Temp_I1_0.1136_50.3_20240511_135123_025000.png
```

各字段含义（已据代码与 CSV 核实）：

- `plot_name`：模板的展示名，来自 `Template_library.csv` 的 `plot_name` 列（如 `Temp_K1`、`Temp_I2` 等）。**不是慢度/方位**。
- `|CCs_s_trig|`：该触发点叠加互相关绝对值（如 `0.1136`），4 位小数。
- `CCs_s_trig_ofMAD`：相关值除以该模板 MAD 后的倍数（带符号，如 `50.3`、`-51.5`），即触发强度以 MAD 为单位；1 位小数。
- 时间戳：触发时刻 `t_trig`，精确到微秒。

### 参数子目录命名规律

- 脚本 1/3：`kur{kur0}_{kur1}_C{C0}_{C1}_win{winL}_{winR}/`，如 `kur20_1000_C0.03_1_win1.5_1.5/`。
- 脚本 2：再追加 `_Z{Zl}_{Zr}_p{p}_q{q}`。
- 字段对应 `Config` 的 `kurtosis_range / C_trig_range / Search_win`，即「本批图所用的触发点筛选区间与窗口」。

### config.json

由各脚本 `Config._save_json` 写出，记录所有可 JSON 序列化的参数与全部输入/输出路径。是「这批图用什么参数、读了哪些数据」的权威证据。注意脚本 1 的 `config.json` 与磁盘实际子目录之间存在参数不一致（config.json 记录的是某次中间调参时的参数），以磁盘子目录名为准。

### 中间数组（仅内存，不落盘）

- `CCs_f` / `CCs_f_calc`：`CCs_comp(data,temp)` 输出，形状 `(data.shape[0]-temp.shape[0]+1, 通道数)`。
- `fk_results=(freqs, wavenums, ampspec)`：见 `spectrum.py`。
- `Ztdt_results=(dist_series, lonely_series, quantile_series, avg_series)`：见 `group_similarity.py`。

这些都只在图里呈现，不保存为文件。
