## 二、脚本逐个说明

### 1_label_STALTA_with_template_plus_NOAeq.py —— 给 STA/LTA 目录做信息增强

**作用**：以 STA/LTA 目录为主表，对每个 STA/LTA 事件做时间最近邻匹配，追加「是否对应 NOA 地震」「是否被 MF 检测到」等列，输出增强版 STA/LTA 目录。

**输入**：
- STA/LTA 原始 CSV（`Config.stalta_catalog_path`，读取包内 `IN_STALTA_cata/sta_lta_catalog.csv`，即外部 `stalta_clustering/.../sta_lta_catalog.csv` 的副本，**外部数据依赖**，在 Zenodo 存档里）。
- NOA IMS 文件（`{PROJECT_ROOT}/IN_NOA_cata/200km_distance/IMS_20240425_20240623_263.txt`）。
- MF 目录（`{PROJECT_ROOT}/Output_4_.../level_20/MagRegression/Events_classified_Real_Mag.csv`）。
- 关键参数：`level=20`；时间窗 `2024-04-24 10:20` 至 `2024-06-22 17:10`；NOA 匹配容差 3 s、MF 匹配容差 2 s；NOA 空间筛选范围 `lat[36.5,40.38] lon[18.844,22.676] mag≥0`。

**输出**：`Output_6_Compare_MF_stalta_NOA/level_20/eq_list_to_plot/stalta_catalog_enriched.csv`（制表符分隔）。
原始 5 列基础上追加 11 列：`noa_match_flag, noa_time_diff_s, noa_magnitude, noa_latitude, noa_longitude, noa_distance_km, mf_match_flag, mf_time_diff_s, mf_template_name, mf_real_mag, mf_sccs`。

**核心逻辑**：
1. 读 STA/LTA CSV，按 `peak_time` 时间窗筛选排序。
2. 解析 NOA IMS 为 DataFrame，按时间/经纬度/震级筛选，**按 `STA_arrival_time` 去重**。
3. 读 MF 目录，按 `Rt_trig` 时间窗筛选。
4. 逐 STA/LTA 事件，分别对 NOA 的 `STA_arrival_time`、MF 的 `Rt_trig` 做绝对时间差最近邻；在容差内则回填对应信息。`noa_distance_km = STA_distance(度) × 111`。

**依赖 functions**：`functions/extract_station_info.extract_station_info`。

**备注**：纯时间匹配，无空间约束。STA/LTA 目录从包内 `IN_STALTA_cata/sta_lta_catalog.csv` 读取（副本在 Zenodo 存档里），复现时须确保该 CSV 已放入此位置。

### 2_label_NOA_with_template_and_detectByMForNot.py —— 给 NOA 目录做空间+检测标签

**作用**：以 NOA 官方目录为主表，对每个 NOA 地震做两件事：(a) 空间上判定它落在哪个 MF 模板区域内；(b) 时间+空间上判定它是否被 MF 检测到，输出带标签的 NOA 目录。

**输入**：
- NOA IMS 文件（同脚本 1）。
- MF 目录（同脚本 1）。
- 模板库 `{PROJECT_ROOT}/Output_0_Template_library/Template_library.csv`（需含 `infile_name, EQ_latitude, EQ_longitude`）。
- 关键参数：`level=20`；时间窗同脚本 1；空间区域半径 `spatial_radius_km=8.0`；MF 检测时间容差 3 s、空间搜索半径 `time_search_radius_km=7.0`；NOA 去重键为 `EQ_time`。

**输出**：`Output_6_Compare_MF_stalta_NOA/level_20/eq_list_to_plot/noa_catalog_labeled.csv`（制表符分隔）。
在 NOA 解析列基础上追加 5 列：`template_region, dist_to_template_center_km, is_detected_by_mf, mf_detection_time_diff_s, mf_template_name`。

**核心逻辑**：
1. 解析 NOA IMS，**按 `EQ_time` 去重**（与脚本 1 的 `STA_arrival_time` 去重不同）。
2. 读 MF 目录与模板库。
3. 逐 NOA 事件：用 `geopy.geodesic` 算到各模板震源的距离；最近模板 ≤ 8 km 则标记归属，否则记 `outside_all_templates`。MF 检测需同时满足时间差 ≤ 3 s **且** 最近模板距离 ≤ 7 km。

**依赖 functions**：`functions/extract_station_info.extract_station_info`；`geopy.distance.geodesic`。

### 3_plot_catalog_MF_stalta_NOA.py —— 三目录综合对比大图

**作用**：把 MF/STA-LTA/NOA 三套目录按「逐模板 + 总览」分行，绘制时间-震级散点、时间直方图、震级频次直方图（FMD）与 G-R 累积曲线的多面板综合图。

**输入**（只读对齐好的 CSV）：
- `Output_6_.../eq_list_to_plot/stalta_catalog_enriched.csv`（脚本 1 产物）。
- `Output_6_.../eq_list_to_plot/noa_catalog_labeled.csv`（脚本 2 产物）。
- MF 目录 `Output_4_.../Events_classified_Real_Mag.csv`（直接再读一遍）。
- 关键参数：`level=20`；绘图时间窗 `2024-04-24 10:15` 至 `2024-06-22 16:15`（**注意比脚本 1/2 匹配窗略宽**）；5 个模板 K1/K2/K3/I1/I2。

**输出**：`Output_6_Compare_MF_stalta_NOA/level_20/compare_figures/3_catalog_comparison_plot.png`。

**核心逻辑**：按 `Temp_name_list` 逐模板取子集，每个模板画 4 panel：①时间-震级散点（MF 红圆/STA-LTA 绿十字/NOA 蓝星）；②每 2 h 计数直方图（log y）；③震级频次直方图；④G-R 累积曲线+MF b 值拟合。最后追加一行「Overall 总览」。图幅 `figsize=(55, 11×6)`，dpi=150。

**依赖 functions**：无（全部内联，仅用 numpy/pandas/matplotlib/scipy）。

## 四、脚本间关键差异

**脚本 1 vs 脚本 2（视角不同，互补，缺一不可）**：
- 脚本 1 以 STA/LTA 为主表，**纯时间匹配**（NOA 容差 3 s、MF 容差 2 s），NOA 去重按 `STA_arrival_time`。
- 脚本 2 以 NOA 为主表，**空间标注（8 km）+ 时间检测（3 s 且 7 km）**，NOA 去重按 `EQ_time`。

**时间窗微差（注意）**：脚本 1/2 匹配窗 `10:20～17:10`；脚本 3 绘图窗 `10:15～16:15`；脚本 4/4' 不显式裁剪（用 CSV 全量）。三处端点不完全一致，属各自独立设定。

## 五、产出数据说明

本文件夹自身不存数据，产物写到 `Output_6_Compare_MF_stalta_NOA/`（详见该目录的说明文档）。

### stalta_catalog_enriched.csv 字段

原始 5 列：`Unnamed: 0`（行索引）、`peak_time`（STA/LTA 触发峰值时刻）、`peak_amp`、`peak_score`、`peak_dist`、`max_amp_mean`。

脚本 1 追加 11 列：

| 列名 | 含义 |
|------|------|
| `noa_match_flag` | bool，是否在 3 s 内匹配到 NOA 地震 |
| `noa_time_diff_s` | 与最近 NOA 地震的时间差（秒），未匹配为 NaN |
| `noa_magnitude` | 匹配到的 NOA 震级（ML） |
| `noa_latitude` / `noa_longitude` | 匹配到的 NOA 震源位置（度） |
| `noa_distance_km` | NOA `STA_distance`（度）× 111 转换为 km |
| `mf_match_flag` | bool，是否在 2 s 内匹配到 MF 检测 |
| `mf_time_diff_s` | 与最近 MF 检测的时间差（秒），未匹配为 NaN |
| `mf_template_name` | 匹配到的 MF 模板名，未匹配为 `unmatched` |
| `mf_real_mag` | 匹配到的 MF 回归震级（`Real_Mag`） |
| `mf_sccs` | 匹配到的 MF 叠加互相关值（`CCs_s_trig`） |

### noa_catalog_labeled.csv 字段

NOA 解析列：`EQ_time, EQ_latitude, EQ_longitude, EQ_depth, EQ_magnitude(ML), STA_name(=FSK), STA_distance(度), STA_azimuth, STA_phase, STA_arrival_time`。

脚本 2 追加 5 列：

| 列名 | 含义 |
|------|------|
| `template_region` | 最近模板名（如 `template_10_80Hz`），距所有模板 >8 km 时为 `outside_all_templates` |
| `dist_to_template_center_km` | 震源到最近模板中心的测地线距离（km） |
| `is_detected_by_mf` | bool，该 NOA 地震是否被 MF 检测到（时间 ≤ 3 s 且空间 ≤ 7 km） |
| `mf_detection_time_diff_s` | MF 检测时刻与 NOA 到时的时间差（秒），未匹配为 NaN |
| `mf_template_name` | 成功检测时对应的 MF 模板名，未匹配为 `unmatched` |

### 关键上游输入（只读，不在本文件夹）

- MF 目录：TSV，关键列 `Rt_trig`、`Template`、`Real_Mag`、`CCs_s_trig`。
- 模板库：CSV，关键列 `infile_name`、`EQ_latitude/EQ_longitude`、`EQ_magnitude`，共 5 模板（K1/K2/K3/I1/I2）。

- 手工插图 `insert_fig.png` / `insert_fig_flat.png`：非脚本生成，须随附。
