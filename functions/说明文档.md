# `functions/` 共享函数库说明文档

> 适用项目：`yuhan_dasmf_v1.0`（Kefalonia DAS 模板匹配地震检测发布版）
> 本文件夹是**纯函数库**，自身不产出数据；被所有 `Run_*` / `Output_*` 脚本 `import`。
> 所有 `.py` 文件顶部均有一段 `# === dasmf path bootstrap ===` 引导块（从 `__file__` 向上查找 `.dasmf_root` 哨兵得到 `PROJECT_ROOT`，并把 `PROJECT_ROOT` 与 `PROJECT_ROOT/functions` 加入 `sys.path`），属正常设计，请勿删除。

## 一、文件夹概述与在整体流程中的位置

`functions/` 是本发布版的**底层共享代码库**，没有上游数据来源，也不直接产生数据产物；它的「上游」是被各步骤脚本调用，「下游」是各步骤脚本据此读写 DAS h5、计算互相关、触发、分类、估震级、对比 NOA 目录等。

本 release 为单一干净主线：触发使用峰度版（Run_2），分类估震级使用 Run_4 kurtosis 版。流程概览：

```
Run_0  → Run_1 → Run_2 → Run_3 → Run_4 → Run_5 → Run_6
造模板    算SCCs   触发    记录     去重叠    剔假阳    对比出图
                         峰值     分类
                         振幅     估震级
```

## 二、模块逐个说明

### 1. `load_das_h5_PE2024.py` —— DAS 数据底层读取（最关键）
- **作用一句话**：读取 Pascal Edme 下采样后的 DAS h5（`Traces` 数据集、`step`/`scaling`/`header_info` 等属性），按 `[t_start, t_end]` 跨文件拼接，返回 `data, headers, axis`。
- **核心函数**：
  - `load_headers_only(file)`：只读头信息。`fs = 1000/step`，从文件名（`...YYYYMMDD_HHMMSS.f.h5`，取末 22 字符）推断 `t0`；从 `headers/` 数据集按 `offset` 列取 `d0/d1/dx`。
  - `load_file(file)`：读单个 h5 全块，构造 `axis['dd']`（距离）、`axis['tt']`、`axis['date_times']`。
  - `load_das_custom(t_start, t_end, d_start, d_end, input_dir, nth_channel, ...)`：**全流程实际用的函数**。在 `input_dir/*.h5` 及按日期的子目录 `/%Y%m%d/` 内搜文件，跨文件切片并 `np.concatenate`；返回时除以 `amp_scaling` 转应变率。
- **输入**：DAS h5 文件目录（典型为 80 Hz 归档 `DATA_DEC_80Hz_16m_SORTED/`；`Read_DAS_data` 固定读取包内 `IN_DAS_data/continuous_scan_1h/`）。
- **输出**：内存中的 `data[npts, nchan]`、`headers`、`axis`。
- **依赖**：仅 `h5py/numpy`，无项目内依赖。
- **备注**：不处理数据缺口；按文件名推断时间，文件命名格式不符会读不到；是被调用最多的模块，改它影响全局。

### 2. `pydas_readers/`（子包）—— Silixa 原始格式读写 + 信号工具
已添加 `__init__.py`（顶层及各子目录），可作为正规包使用。
- `readers/load_das_h5.py`：读 Silixa PRODML 原始 h5（`Acquisition/Raw[0]/RawData` + PRODML 头），`load_das_custom` 支持 `ichan/mapchan` 按映射取道、`convert=True` 时转应变率。对应 400 Hz/8 m 原始数据。
- `readers/write_das_h5.py`：`write_block()` 把数据按 PRODML 兼容结构写回 h5（float32）。
- `util/block_filters.py`：`block_bandpass()`（Butterworth 带通，先 taper 再 sosfilt）、`chebychev_lowpass_downsamp()`。**被 `compute_correlation.preprocess` 等大量复用**。
- `util/block_cleaning.py`：`taper()` / `demean()` / `detrend()` / `trim()` / `pws_rolling_average()`。预处理基石。
- `util/block_spectra.py`：`spectrum()` / `plot_spectrum()`，DAS 频谱密度图（探索/出图用，非主链必需）。
- `mapping/channel_mapping.py`：`get_mapping()` 从 `Channel_mapping_information_catalouge_v4.1.csv` 读通道→经纬度/距离映射；`MAPPED_FILENAME` 为硬编码相对路径。该映射表属于另一个 DAS 部署，不随本包分发；本 release 里没有任何代码调用 `get_mapping()`。
- **备注**：该子包是通用 DAS 读写滤波库；原始 400 Hz Silixa 格式由 `load_das_h5.py` 读，v1.0 主链用的 80 Hz 下采样格式由顶层 `load_das_h5_PE2024.py` 读，两者不可混用。

### 3. `compute_correlation.py` —— 模板互相关核心
- **作用一句话**：提供叠加互相关 `CCs_comp` 与 DAS 预处理 `preprocess`，是 Run_1 算 SCCs 的算法核心。
- **核心函数**：
  - `moving_average_2d_axis0(data, size)`：沿时间轴滑动平均（`as_strided`），用于归一化互相关的滑动均值/方差。
  - `CCs_comp(data, temp)`：模板沿连续数据滑动的逐时刻归一化互相关 `CCs_f` 与原始 `RAWCCs_f`，输出 `shape=(data_t - temp_t + 1, nchan)`，用 `signal.fftconvolve` 实现。
  - `preprocess(data, fs, f1, f2)`：去空间中位、`detrend`、`block_bandpass`、去时间均值。
- **被用到**：Run_0 造模板、Run_1 算 SCCs、Run_5 复核；`readers.Read_template` 也 import 它的 `preprocess`。
- **依赖**：`pydas_readers.util.block_filters/block_cleaning`。

### 4. `readers.py` —— 全流程 I/O 中枢
- **作用一句话**：封装模板/DAS/SCCs/触发点的读取与 pkl/h5 通用读写。
- **核心函数**：
  - `load_pkl/write_pkl`、`write_h5/load_h5`：通用序列化（`write_h5` 会把 object 数组转 float32 或字节串）。
  - `Read_template(Template, fs,f1,f2, dx,d1,d2, npy_dir)`：从 `npy_dir` 读 `Template.npy`，按距离裁剪并 `preprocess`。
  - `Read_DAS_data(t_start, t_end, fs,f1,f2, dx,d1,d2)`：读 80 Hz DAS、裁剪、`preprocess`。
  - `Read_CCs_stack_h5(IN_dir, Template, t_start, t_end)`：把 Run_1 产出的 10 分钟 SCCs h5（含 `CCs_s`、`RAWCCs_s`）按时间窗拼接成连续序列。是 Run_2/Run_4/Run_5 读取 SCCs 的入口。（注：窗口非整 10 分钟时末段处理可能有偏差。）
  - `Read_CCs_trig_pkl(IN_dir, Template, t_start, t_end)`：读 Run_2 触发点 pkl，拼出 `CCs_s_trig/RAWCCs_s_trig/t_trig/width_trig/t_left/t_right/max_RAWCCs/t_arg_max/max_stalta` 并按时间窗裁剪。
  - `Read_CCs_trig_pkl_toPANDAS(...)`：同上但返回 DataFrame，供 classify 流程使用。
  - `MESSUP_Read_CCs_stack_h5`：**已知有 bug（未排序文件）**，作者明确标废弃，勿用。
- **依赖**：`load_das_h5_PE2024`、`compute_correlation.preprocess`、`pydas_readers`。

### 5. `trigger.py` —— SCCs 阈值触发
- **作用一句话**：在 SCCs 序列上，用「按时间段变化的 MAD × level」阈值触发并在每个簇内取绝对值最大点。
- **核心函数**：
  - `Trigger_with_MADarray(t_start, t_end, fs, CCs_s, t_array, MAD_array, Threshold_level, Minimal_event_interval)`：按 `t_array`（MAD 时间网格）切段，每段用对应 MAD×level 作阈值，分段调用 `Trigger_with_Constant`，输出 `CCs_s_trig, t_trig, t_left, t_right, width_trig`。**主链触发函数**。
  - `Trigger_with_Constant(t_start, fs, CCs_s, Threshold, Minimal_event_interval)`：恒定阈值触发；`|CCs|>Threshold` 置 1，按 `Minimal_event_interval` 聚簇，每簇取 argmax。
- **输入**：SCCs 序列 + MAD 数组（来自 Run_1）。
- **输出**：触发点数组，写入 Run_2 的触发 pkl。
- **依赖**：仅 numpy。

### 6. `classify.py` —— 去重叠分类（模板时移 + 同事件归并）
- **作用一句话**：把多模板、多时刻对同一真实地震的重复触发归并为一条，并做模板走时偏移校正。
- **核心函数（当前在用，pandas 版）**：
  - `Remove_Temp_Offest_forSeries(SRt_trig, Template, DF_Temp_Offset, offset_Type='S')`：用模板偏移表把触发时刻校正为真实地震时刻 `Rt_trig`。
  - `Read_Collapse_group_df(IN_CCs_trig_dir, Temp_name_list, DF_Temp_Offset, MAD_array_dict, t_start, t_end)`：逐模板读触发 pkl→DataFrame，加 `Rt_trig/CCs_s_trig_ofMAD/Template` 列，合并所有模板。
  - `Collapse_with_MAX_CCs(Collapse_group, IN_one_event_interval)`：相邻间隔 < `one_event_interval` 归为一组，组内取 `|CCs_s_trig_ofMAD|` 最大者，标 `Belong_or_not=1`。**去重叠核心**。
- **历史遗留（注释/残缺，勿用）**：`Joint_dict_elem`、`Classification_by_shift`、`Est_Mag_Bias`、`Retrig` 等基于旧 `OUT_dict` 字典结构，已被上述 pandas 版替代；文件开头有一段悬空的无函数名代码块（编辑残迹）。
- **依赖**：`readers`、`load_das_h5_PE2024`、`pydas_readers`。

### 7. `cluster.py` —— 事件相似度与 DAS 截窗
- **作用一句话**：用于模板库去重（事件间互相关）与读取某事件附近 DAS 数据窗。
- **核心函数**：`simple_corr_coef_1D/2D`（相关系数）、`read_DAS_span(tc, t_left, t_right, freq_band, input_dir, dist_start, dist_end, sel_dist)`（读事件附近 DAS、去中位、detrend+bandpass）、`norm_the_flattened_DATA`（展平归一化）。
- **被用到**：Run_0 / Output_0 的事件相似度计算（`2_..._Comp_corr_between_events`）。
- **依赖**：`readers`、`plot`、`trigger`、`pydas_readers`、`load_das_h5_PE2024`。
- **备注**：本模块算「事件×事件」相似度，`compute_correlation.py` 算「模板×连续数据」互相关，二者不可互换。

### 8. `stalta.py` —— STA/LTA 触发
- **作用一句话**：中心化 STA/LTA 计算（按 MAD 或 MAX 归一）、多通道触发与按通道计分聚类。
- **核心函数**：`sta_lta_centred_unnorm` / `sta_lta_centred`（单道，默认 MAD 归一）、`sta_lta_centred_multichan`（多道 waterfall）、`trig_onechan_and_outindex`（单道触发取峰）、`trig_allchan_and_collapsed_index`（跨道聚合，输出 `index_arg_max, score, csl_value/score, empty_no`）。
- **被用到**：Run_0 校验模板（地震是否 STA/LTA 可见）、Run_2 峰度触发、Run_5 复核。
- **依赖**：`plot`、`pydas_readers`、`load_das_h5_PE2024`。
- **备注**：原先指向外部 `stalta_clustering/` 目录的 `sys.path.append` 已删除（见第 24–25 行注释）；`plot_if_really_a_event_STALTA` 函数体几乎全被注释。

### 9. `extract_station_info.py` —— 解析 NOA IMS 公报
- **作用一句话**：给定 IMS1.0 格式地震列表文件和台站名，正则提取该台站记录的所有地震（震时/经纬/深度/震级/距离/方位/震相/到时）。
- **核心函数**：`extract_station_info(file_path, station_name)` → list[dict]。
- **被用到**：Run_0 选模板、Run_4 估震级校验、Run_6 对比 NOA。
- **依赖**：仅 `re/os/datetime`，无项目依赖，自包含、易复用。

### 10. `noa.py` —— NOA 台站码与坐标
- **作用一句话**：从 IMS 文件提取台站代码集合；从 EIDA FDSN web service 拉取台站经纬度。
- **核心函数**：`extract_station_codes(ims_filepath)`、`load_station_inventory(network_codes=['HL','HP','HT','5B'])`（联网请求 `eida.gein.noa.gr`）。
- **被用到**：仅 Run_6 的出图脚本（`4_plot_detection_power_mag_dist_map*.py`）。
- **依赖**：`pandas/requests/geopandas/cartopy/geopy` 等较重地理绘图库。
- **备注**：`load_station_inventory` **需联网**；仅出图用，非检测主链必需。

### 11. `das_mffi_io.py` —— MFFI 仪器 IO + DAS sum 工具
- **作用一句话**：读取/换算 MFFI（单点光纤干涉仪，与 DAS 是不同仪器）数据并与 DAS sum 对比绘图；含 `read_das_full_sum` 等 DAS 求和工具。
- **核心函数**：`read_das_full_sum`（读 DAS 并按距离求和、转 d/v/a）、`das_full_sum_filter_all_in_one`、`read_mffi_any` / `read_mffi_any_v2`（读 MFFI h5、换算应变，v2 支持跨日补零）、多个 `plot_*`/`waterfall_simple`。
- **被用到**：Run_0 / Output_0 造模板时（`2_..._Produce_templates`、`3_add_SNR...`），主要用 `read_das_full_sum`/绘图；MFFI 数据路径为包内 `IN_MFFI_data/kefalonia_ts_h5_80Hz/`（MFFI 数据不随包分发）；`read_das_full_sum` 用 DAS 目录字符串选择读取函数和道间距，只认包内默认目录 `IN_DAS_data/continuous_scan_1h/`（80 Hz）、`IN_DAS_data/DATA_DEC_8Hz_16m_SORTED/`、`IN_DAS_data/DATA_RAW_400Hz_8m/`。
- **依赖**：`pydas_readers`、`load_das_h5_PE2024`、`h5py`。
- **备注**：MFFI 部分与 DAS 主检测链关系不大，属辅助/对比；物理换算常数（`L=2*14976`、`phase_to_strain` 等）已固化在代码中。

### 12. `plot.py` —— 通用绘图工具
- **作用一句话**：时间轴刻度格式化、DAS waterfall 出图、GridSpec 网格生成。
- **核心函数**：`Ticks_xaxis_day_or_hour` / `Ticks_xaxis_minute_or_second`、`waterfall_date`、`generate_gs_grid`。
- **被用到**：全流程出图。
- **依赖**：仅 matplotlib/numpy，自包含。

### 13. `extract.py` —— 逐通道峰值振幅记录
- **作用一句话**：`Record_Shift_Bychan`（在触发时刻附近窗内逐通道记录 CCs 最大值与时移、对应 RAWCCs）、`Record_DataMax_Bychan`（逐通道记录数据峰值与时移）。
- **被用到**：Run_3 记录峰值振幅。
- **依赖**：`readers`、`load_das_h5_PE2024`、`pydas_readers`。

### 14. `append_cut_convert.py` —— 历史遗留（无外部 consumer，可无视）
- **作用一句话**：旧版基于 `OUT_dict` 字典的拼接（`Joint_dict_elem`）、时间裁剪、加模板名、模板时移等逻辑。
- **现状**：全项目无任何脚本 `import` 它；功能已被 `classify.py`/`readers.py` 的 pandas 版替代。判定为废弃死代码，已保留原地但无需理会。

## 三、模块之间的依赖关系（库内部）

```
pydas_readers/util/block_cleaning, block_filters   (最底层信号工具，无项目依赖)
        │
        ├──> compute_correlation.preprocess / CCs_comp
        │            │
        │            └──> readers.Read_template / Read_DAS_data
        │
load_das_h5_PE2024.load_das_custom  (DAS h5 读取，几乎被所有模块 import)
        │
        ├──> readers.*  (Read_CCs_stack_h5 / Read_CCs_trig_pkl / pkl,h5 读写)
        │            │
        │            ├──> classify.* (Read_Collapse_group_df → Collapse_with_MAX_CCs)
        │            └──> cluster.*  (read_DAS_span 等)
        │
        ├──> trigger.Trigger_with_MADarray  (依赖 readers 提供的 MAD 数组)
        ├──> stalta.*
        └──> das_mffi_io.*（Run_0 造模板辅助）

plot.* / extract_station_info.* / noa.*  : 相对独立的工具/解析/地理模块
extract.*  : Run_3 逐通道峰值记录
append_cut_convert.*  : 历史遗留，无外部调用
```

**`load_das_h5_PE2024` + `pydas_readers` + `compute_correlation` + `readers` 是不可拆的内核**，`trigger`/`classify`/`plot` 是其上的处理层。

库被各步骤调用的顺序（本 release 主线）：

```
Run_0(extract_station_info, cluster, stalta, compute_correlation, das_mffi_io, plot)
   → Run_1(compute_correlation.CCs_comp, readers, plot)           ← 产 SCCs/MAD
   → Run_2(readers.Read_CCs_stack_h5, trigger.Trigger_with_MADarray, stalta, plot)  ← 触发
   → Run_3(readers, trigger, extract, plot, load_das_h5_PE2024)   ← 记录峰值振幅
   → Run_4(classify.Read_Collapse_group_df + Collapse_with_MAX_CCs,
           trigger, readers, extract_station_info, plot)           ← 去重叠/分类/估震级
   → Run_5(compute_correlation, stalta, trigger, classify, plot)  ← f-k/峰度剔假阳性
   → Run_6(extract_station_info, noa, plot)                       ← 与 STA/LTA、NOA 对比
```

## 四、模块/函数变体之间的差异（重点）

1. **`compute_correlation.py`（模板×连续数据）vs `cluster.py`（事件×事件）**：
   - `compute_correlation.CCs_comp`：模板沿连续数据滑动求互相关序列，用于**检测**（Run_1 算 SCCs）。
   - `cluster.simple_corr_coef_2D` / `read_DAS_span`：算两个已知事件波形的相似度，用于**模板去重**（Run_0）。
   - 二者不可互换。

2. **`classify.py` 内两套实现：pandas 版 vs 旧 dict 版**：
   - 在用：`Read_Collapse_group_df` + `Collapse_with_MAX_CCs` + `Remove_Temp_Offest_forSeries`（DataFrame，`Belong_or_not` 标记）。
   - 废弃（注释/残缺）：`Joint_dict_elem`/`Classification_by_shift`/`Est_Mag_Bias`/`Retrig`（基于 `OUT_dict` 字典）。两套**功能目标相同（去重叠）但数据结构不同**，不可混用。`append_cut_convert.py` 是旧 dict 版的配套逻辑，已整体废弃。

3. **`readers.Read_CCs_stack_h5` vs `MESSUP_Read_CCs_stack_h5`**：后者因未对文件排序而读出乱序数据，作者明确标 `!!错`，已废弃；用前者。

4. **`Read_CCs_trig_pkl`（返回多个 numpy 数组）vs `Read_CCs_trig_pkl_toPANDAS`（返回 DataFrame）**：内容等价，后者供 pandas 流程（classify）使用；`Read_CCs_stack_h5` 读连续 SCCs，`Read_CCs_trig_pkl` 读触发点，不要混淆。

5. **`pydas_readers/readers/load_das_h5.py` vs 顶层 `load_das_h5_PE2024.py`**：
   - `load_das_h5`（Daniel）读 Silixa 原始 PRODML（400 Hz/8 m，`Acquisition/Raw[0]/RawData`），支持 `ichan/mapchan`。
   - `load_das_h5_PE2024`（Pascal 派生）读下采样后的 h5（80 Hz/16 m，`Traces`，fs 由 `step` 算）。本 release 主链用后者。

6. **`sta_lta_centred` vs `sta_lta_centred_unnorm`**：前者额外按 MAD（或 MAX）归一，后者返回原始 STA/LTA。

7. **`read_mffi_any` vs `read_mffi_any_v2`**：v2 支持跨日、对缺口补零、更鲁棒；v1 仅同日单文件。均属 MFFI 辅助。

## 五、数据格式约定

本文件夹是函数库，**不直接产生数据产物**。Zenodo 存档里随库携带两类静态资源（GitHub 版都不含）：

- `pydas_readers/mapping/Channel_mapping_information_catalouge_v4.1.csv`（GitHub 版不含：它属于另一个 DAS 部署，`get_mapping()` 在本 release 中从未被调用）：通道→经纬度/距离映射表，被 `channel_mapping.get_mapping()` 读取（`skiprows=10`），列含 `Chan Number`、`Distance_mapped (m)`、`actual_dx`、`Latitude/Longitude`、`Keep`、`Good - not noise` 等。`MAPPED_FILENAME` 默认硬编码相对路径 `./pydas_readers/mapping/...v4.1.csv`。
- `__pycache__/`、`.DS_Store`：缓存与系统文件，可忽略（GitHub 版已去掉）。

库读写的数据格式约定（由其它步骤产生/消费，函数库定义其 schema）：
- **SCCs h5**（Run_1 产）：dataset `CCs_s`（叠加归一化互相关序列，fs=80）、`RAWCCs_s`；由 `readers.Read_CCs_stack_h5` 读。
- **触发 pkl**（Run_2 产）：keys 含 `t_trig/CCs_s_trig/RAWCCs_s_trig/width_trig/t_left/t_right/max_RAWCCs/t_arg_max/max_stalta`；由 `readers.Read_CCs_trig_pkl(_toPANDAS)` 读。
- **模板 npy**（Run_0 产）：`template_*.npy`，二维 `[time, channel]`；由 `readers.Read_template` 读（按 `dx` 裁剪后 `preprocess`）。
